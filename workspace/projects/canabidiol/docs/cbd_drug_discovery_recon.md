# CBD Drug Discovery Reconnaissance

## Key Molecular Targets of CBD
- CB1: negative allosteric modulator (NAM)
- CB2: weak agonist / possible inverse agonist
- GPR55: antagonist (anticonvulsant)
- GPR3/6/12: inverse agonist (Alzheimer's target)
- 5-HT1A: agonist (anxiolytic, antidepressant)
- TRPV1/2: agonist (pain, desensitization)
- TRPA1: agonist
- TRPM8: antagonist
- PPARγ: agonist (anti-inflammatory, Nrf2 cooperation)
- Adenosine A2A: agonist (anti-inflammatory, neuroprotection)
- Voltage-gated Na+/K+ channels: inhibitor (anticonvulsant)
- FAAH: indirect inhibitor (raises AEA levels)
- CYP3A4/CYP2C: enzyme inhibitor (DDI risk)

## Open Issues for Drug Discovery
1. Unknown in-vivo MOA (2024)
2. Poor oral bioavailability (~6% fasting)
3. CYP-mediated drug-drug interactions
4. Hepatotoxicity (ALT/AST elevation)
5. Polypharmacology complexity (>65 targets)
6. Inverted U dose-response curves
7. Lack of randomized controlled trials
8. Oxidative stress mechanism unclear
9. Neuroinflammation pathways need elucidation

## Key Signaling Pathways
- ECS: AEA/2-AG → CB1/CB2 → MAPK, PI3K/AKT/mTOR
- Inflammation: NFκB → COX2, TNFα, IL-1β, IL-6
- Antioxidant: Nrf2/Keap1 → ARE → HO-1, SOD, CAT
- PPARγ → ubiquitination of p65 → anti-inflammatory
- TRPV1 → Ca2+ → NFAT → cytokines
- 5-HT1A → anxiolytic, membrane antioxidant
- GPR55 → Ca2+, anticonvulsant
