# CBD vs Alzheimer's Drug Discovery: Comparative Analysis

## The AD "Graveyard" Problem
- 99.6% failure rate in AD clinical trials (2002-2012)
- 182 clinical trials testing 138 drugs (as of 2025)
- Amyloid hypothesis dominated for 30 years; amyloid-only drugs consistently failed
- Only 2 anti-amyloid mAbs approved (lecanemab, donanemab) - efficacy uncertain, side effects (ARIA)
- Cholinesterase inhibitors (donepezil, rivastigmine, galantamine) = symptomatic only
- Memantine (NMDA antagonist) = modest benefit
- Neuroinflammation recognized as central AD driver (microglia, NFκB, cytokines)
- Oxidative stress, Ca2+ dyshomeostasis, mitochondrial failure all contribute
- Multi-target approach now considered essential (paradigm shift)

## Parallel Open Issues: CBD vs AD

| Dimension           | CBD Drug Discovery        | AD Drug Discovery         |
|---------------------|---------------------------|---------------------------|
| Target complexity   | 65+ known targets         | Aβ, tau, neuroinflam, etc |
| Paradigm            | Polypharmacology native   | Single→multi-target shift |
| Failure rate        | Few RCTs completed        | 99.6% trial failure       |
| Bioavailability     | ~6% oral                  | BBB penetration challenge |
| Biomarkers          | No validated PD markers   | Amyloid PET, CSF Aβ/tau  |
| Safety              | Hepatotox, DDIs           | ARIA, brain edema (mAbs)  |
| Dose-response       | Inverted U-curve          | Narrow therapeutic window |
| Mechanism clarity   | Unknown in-vivo MOA       | Amyloid vs tau debate     |
| Inflammation axis   | PPARγ→NFκB, Nrf2→ARE      | Microglia, TREM2, NFκB    |
| Oxidative stress    | ROS scavenging, Nrf2      | Mitochondrial Aβ, ROS     |

## Key Insight: Mirror-Image Problems
AD drug discovery spent decades trying to find more targets after the amyloid-only
approach failed. CBD drug discovery has the opposite problem: too many targets,
needing to isolate which ones drive therapeutic effects. CBD's native polypharmacology
hits precisely the multi-target profile that AD researchers now seek.

## CBD-AD Convergence Points (model targets)
1. GPR3/6/12 inverse agonism → reduces γ-secretase → ↓Aβ production
2. PPARγ agonism → p65 ubiquitination → ↓NFκB → ↓neuroinflammation
3. Nrf2/Keap1 → ARE → HO-1, SOD → ↓oxidative damage to neurons
4. A2A agonism → anti-inflammatory in microglia
5. 5-HT1A agonism → neuroprotection, BDNF upregulation
6. TRPV1 → Ca2+ modulation → relevant to AD Ca2+ dyshomeostasis

## Proposed Integrated Model: CBD-AD Neuroprotection

### Places (species)
- CBD, GPR3, γ-secretase, APP, Aβ_monomer, Aβ_oligomer
- PPARγ, NFκB_p65, TNFα, IL6, IL1β
- Nrf2, Keap1, HO1, SOD, ROS
- Microglia_resting, Microglia_active
- Neuron_health, BDNF, 5HT1A

### Transitions (reactions)
- Aβ production (APP → Aβ monomers via γ-secretase)
- Aβ aggregation (monomers → oligomers)
- Neuroinflammation cascade (Aβ oligomers → microglial activation → NFκB → cytokines)
- Oxidative damage (activated microglia + Aβ → ROS → neuronal damage)
- Neuroprotection via CBD (GPR3 inhibition, PPARγ activation, Nrf2 induction, 5-HT1A/BDNF)
- Microglial activation and resolution

### Model Arms
1. **Aβ production arm**: APP → γ-secretase → Aβ monomers → oligomers (CBD inhibits via GPR3)
2. **Neuroinflammation arm**: Aβ oligomers → microglial activation → NFκB → TNFα/IL-6/IL-1β (CBD inhibits via PPARγ)
3. **Oxidative stress arm**: activated microglia + Aβ → ROS → neuronal damage (CBD activates Nrf2 → HO-1/SOD)
4. **Neuroprotection arm**: CBD → 5-HT1A → BDNF → neuronal survival
