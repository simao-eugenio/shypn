## Critical issues 🚨

### Issue G4 — dose protocol covers only 18 h of 168 h horizon

```
evt_load    @ t > 0.1
evt_maint_1 @ t > DOSE_INTERVAL    (6 h)
evt_maint_2 @ t > 2·DOSE_INTERVAL  (12 h)
evt_maint_3 @ t > 3·DOSE_INTERVAL  (18 h)
```

After 18 h: no further dosing. CBD plasma t½ ≈ 3 h → drained by ~30 h
→ next 6 days run with zero treatment.

Endpoint `CBD_plasma_final = 0` in all cells (even MAINT=5);
`CBD_intracellular_final = 6.25e-11` (numerical noise). The MAINT axis
is silent at endpoint metrics because CBD evaporated by t = 30 h.

**Fix needed (G4):** add 28 dose events (6 h cadence × 7 d), or use a
recurring/period event mechanism if SHyPN supports it, or generate via
script. Until G4 lands, the chronic horizon is meaningless for any
endpoint-based therapeutic readout.

### Issue G3b' — suppression too aggressive (K = 0.1)

`(1 − NFkB/(0.1+NFkB))` was calibrated on Q3 24 h data where NFkB
stayed in [0.025, 0.243]. At chronic 7 d with no sustained CBD, NFkB
sits at [0.95, 3.51] — far past the K=0.1 pivot. Suppression multiplier:

| Cond | NFkB | T21 multiplier |
|---|---:|---:|
| D=0 (untreated) | 0.95 | 0.095 (recovery 9.5 % of normal) |
| D=2 | 2.37 | 0.040 |
| D=5 | 3.51 | 0.028 |

Combined with BDNF=0 in all conditions, T21 BDNF_neuroprotection
fires **0 times in every cell**, NH collapses to 0 even in healthy
control (DSEV=0).

**Fix (G3b'):** raise K from 0.1 → 2.0. Multiplier table:

| NFkB | mult @ K=0.1 | mult @ K=2.0 |
|---:|---:|---:|
| 0.025 (clean control) | 0.80 | 0.99 |
| 0.10 (mild)           | 0.50 | 0.95 |
| 0.95 (untreated D=0)  | 0.095 | 0.68 |
| 2.37 (D=2 untreated)  | 0.040 | 0.46 |
| 3.51 (D=5 untreated)  | 0.028 | 0.36 |

Healthy state recovers fully; severely inflamed state still suppressed
to 28-46 % — preserves G3b's correction without floor-collapsing NH.
