## Headline finding — global attractor flip on a 4× rate softening

**G5a's single-line ROS-damage softening flipped the model's global
attractor.** The system has at least two stable basins; Q4r samples
basin **A1** (GSH-replete), Q5 samples basin **A2** (GSH-oxidized).
All 30 reps × 13 cells in Q5 (390 trajectories) converged to A2 with
no exceptions. The IC₅₀ measurement we set out to do is meaningful
*within* basin A2 — but cross-comparison with Q4r is invalid because
the systems aren't on the same manifold.

This is a **scientifically interesting result, not a regression**.
The model encodes the well-documented bistability of the cellular
redox / Aβ-aggregation system: small perturbations near a basin
boundary trigger global state changes.

## Mechanistic anatomy of basin A2 ("GSSG-locked, Aβ-cleared, NH-collapsed")

### Bistability 1 — redox cycle (GSH ↔ GSSG)

```
GSH → GSSG   Antioxidant_Scavenging   rate = 0.05·GSH·ROS/(5+ROS) + (SOD/HO1 terms not on GSH)
GSSG → GSH   Glutathione_Reductase    rate = 0.06·GSSG
```

Steady-state ratio at ROS = 49 (Q5 endpoint):
`GSH/GSSG = 0.06 / (0.05 · 49/54) = 1.32` → expected GSH ≈ 41, GSSG ≈ 31.

Both runs are **far from this analytical equilibrium** — Q4r sits at
the GSH end (72.5/0), Q5 at the GSSG end (0/72.5). The cycle is
slow enough relative to ROS transients that early ROS spikes determine
which end gets locked in. Once GSH reaches zero, scavenging stops
(rate ∝ GSH), so any ROS pulse just grows GSSG without a GSH-supply
to drain. Reverse trap also exists at the GSH end with low ROS.

### Bistability 2 — Aβ monomer fate

```
Abeta_Monomer_Clearance:   rate = 0.05 · AbM / Age_factor   (linear in AbM)
Abeta_Aggregation:          rate = 0.05 · AbM² · Tf · ...   (quadratic in AbM)
```

Below ~1 µM AbM, clearance > aggregation; above, aggregation runs
away and produces persistent oligomers/plaques. Q5 firings:

|                              | Q4r (A1) | Q5 (A2) |
|------------------------------|---------:|--------:|
| Abeta_Production_firings     | 35 329   | 36 898  |
| Abeta_Monomer_Clearance      | 13 432   | **92 986** |
| Abeta_Aggregation            | **30 000** | **0**   |

Same Aβ production, but Q5's trajectory keeps AbM below the aggregation
threshold so all monomer is cleared as fast as it's made.

### Why NH crashes despite Aβ = 0

Without aggregated Aβ, AbO term in T20 Neurotoxicity is zero. ROS
contribution at ROS=49: `0.001·29/44 ≈ 6.6e-4 /s` — small but not
zero (this is the term G5a softened). Over 7 d this gives ~400
death events. **97 actually fired** in Q5 — Neurotoxicity is acting
slowly throughout.

The killer is the BDNF cycle. T21 recovery rate
`0.05 · BDNF/(20+BDNF) · (100−NH)/100 · ...` is **zero whenever
BDNF = 0**. With BDNF stuck at 0, NH cannot recover from any
neurotoxicity, so it slowly drains to the ~0 floor. BDNF=0 itself
is an absorbing state under the consumption-via-rate dynamics
(production should regenerate BDNF, but apparently the Q5 trajectory
also crashed BDNF — needs trajectory mining to see when).

So basin A2 is "Aβ-cleared, redox-stuck-at-GSSG, BDNF-cycle-broken,
NH-decayed". It's a **distinct disease attractor** even without
classical AD pathology — a phenotype of "oxidative collapse" rather
than "amyloid disease". Biologically, this matches a documented
phenomenon: chronic GSH depletion can drive neurodegeneration
through pathways orthogonal to Aβ.

### Why CBD doesn't rescue A2 in this run

CBD's dominant action is via PPARg → ↓NFkB → ↓TNFa → ↓IKK → fewer
inflammation events. None of those terms touch GSH/GSSG directly,
so once trajectories enter A2, the redox-trapped state is impervious
to MAINT_DOSE.

This explains why M1 microglia and NFkB Hill curves still respond
to MAINT (those pathways are intact) but NH and BDNF stay flat.

## What the user is right about (and what changes our methodology)

The user's instinct — *"each sweep probably samples one basin or sits
on a basin boundary; analyze the model as the stochastic system it
is"* — is correct and reframes the entire iteration cycle:

1. **A single sweep is one Monte-Carlo sample of a multi-attractor
   landscape.** Variance reported within a cell tells us about
   stochastic spread *inside one basin*, not about which basin we'd
   land in next time.
2. **Patch verification ≠ behaviour verification.** G5a is correctly
   applied (model_snapshot.shy verified), but its effect is
   non-monotone in any single observable because it shifted basin
   boundaries, not just rate magnitudes.
3. **A model passing one acceptance criterion in basin A1 may fail
   it in basin A2** — and previous "fixes" (G3b', G4) were tuned
   inside A1.

### Concrete methodology updates

- **Always run a basin-test sweep before / alongside parameter sweeps.**
  Several deliberately perturbed initial conditions (high/low GSH,
  high/low BDNF, high/low AbM) under fixed MAINT/DSEV to map which
  basins the protocol can reach.
- **Treat replicate variance as basin-internal noise.** When σ ≈ 0
  on key endpoints despite varied seeds, the system is **not**
  necessarily broken — it may be in a deep basin where stochastic
  spread is small. Cross-check with another seed family or a
  perturbed-IC sweep.
- **Annotate runs with basin label.** Add a post-run classifier:
  *if* GSH > 50 ⇒ A1, else if GSSG > 50 ⇒ A2, else ⇒ transitional.
  Provenance gets a `basin: "A1" | "A2" | "transitional"` field.
- **Patch sensitivity ≠ small.** Even surgical one-line rate edits
  can shift basin boundaries. Always re-baseline (DSEV=0.5, MAINT=5)
  immediately after any model patch and compare against the previous
  baseline before reading new sweep results.
