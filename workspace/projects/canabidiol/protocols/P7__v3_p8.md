> **Pairing.** Model: [`models/cbd_ad_neuroprotection_v3_p8.shy`](../models/cbd_ad_neuroprotection_v3_p8.shy)

> capacities=∞; `is_environment_aware` stripped; defaults
> `LOADING_DOSE=10 µM`, `MAINT_DOSE=5 µM`, `DOSE_INTERVAL=86400 s`).
>
> **For P7, the canonical run zeroes every event-driving knob** so the
> object-net is exercised in pure homeostasis mode.

## Hypothesis

The v3_p8 object-net, initialised at its healthy `M₀` and run with
**all event multipliers at zero** (`Disease_Severity = 0`,
`LOADING_DOSE = 0`, `MAINT_DOSE = 0`), maintains a healthy fixed
point over 24 h:

- NFκB stays sequestered (NFkB_IkB ≈ 50, NFkB_p65 ≈ 5).
- Cytokines (TNFα, IL-1β, IL-6, COX-2) remain near M₀ (≈ 0.5 each).
- ROS / antioxidant axis is in balance (ROS small, GSH ≈ 70).
- Aβ monomer / oligomer / plaque do not accumulate.
- Microglia stay M2-dominated (M1 ≈ 5, M2 ≈ 40).
- Neuron_Health = 100 throughout.

A failure to hold any of these is a **calibration bug in v3_p8**, not
a disease phenotype — Pattern A discipline forbids events from doing
work in this condition, so all drift must be attributable to the
biology rate functions.

## Acceptance criteria

| Marker | Target | Tolerance | Failure mode if violated |

| `IL1b`, `IL6`, `COX2` | ≤ 2 | +1 | Same as above; `T7` transcription unchecked |

## Falsification rule

If any acceptance criterion is violated at `Disease_Severity = 0`,
**v3_p8 is not a valid baseline** and patches P1–P6 cannot be
attributed cleanly to disease/treatment effects. The model must be
re-patched (v3_p9) before any further protocol re-runs.
