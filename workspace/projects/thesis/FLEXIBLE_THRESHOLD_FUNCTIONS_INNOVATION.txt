CRITICAL CLARIFICATION:
=======================
The SHYpn innovation is NOT the inhibitor arc itself (which is classical),
but rather the FLEXIBLE THRESHOLD FUNCTION that allows placing Hill inhibition
directly on the arc instead of in the rate law.

CONCEPTUAL DISTINCTION:
=======================

CLASSICAL INHIBITOR ARC:
------------------------
- Enabling condition: M(p) < Δ where Δ = CONSTANT
- Example: PFK enabled iff M(ATP) < 3.0 mM
- Limitation: Only supports simple threshold blocking
- Regulation still requires rate law complexity

SHYPN FLEXIBLE THRESHOLD FUNCTION:
-----------------------------------
- Enabling condition: M(p) < Δ(concentration) where Δ = FUNCTION
- Example: PFK enabled iff M(ATP) < Δ_Hill([ATP])
- Innovation: Hill inhibition encoded on arc topology
- Benefit: Rate law simplified, separation of concerns

KEY INNOVATION: SEPARATION OF CONCERNS
=======================================

WITHOUT SHYpn (Classical Approach):
-----------------------------------
Rate Law = Stoichiometric Kinetics + Regulatory Logic (MIXED)

v = V_max · [F6P]/(K_m + [F6P]) · 1/(1 + ([ATP]/K_i)^n)
        \_____________________/   \____________________/
         Stoichiometric part      Regulatory part (Hill)

Problems:
- Regulation hidden in rate equation
- Cannot separate kinetic from regulatory errors
- Modifications require editing complex rate laws
- Visual topology doesn't show regulatory structure

WITH SHYpn (Flexible Threshold Functions):
-------------------------------------------
Rate Law = ONLY Stoichiometric Kinetics (SIMPLIFIED)
Arc Threshold = ONLY Regulatory Logic (SEPARATED)

Rate law:
v = V_max · [F6P]/(K_m + [F6P])
    \__________________________/
     Pure Michaelis-Menten

Arc threshold function:
Δ_Hill([ATP]) = K_i · (1 + ([ATP]/K_i)^n)^(-1/n)
                \___________________________/
                 Hill inhibition on arc

Benefits:
✓ Regulation explicit on arc topology
✓ Rate law simplified (only stoichiometric kinetics)
✓ Regulatory modifications affect only arc, not transition
✓ Visual inspection reveals regulatory architecture
✓ Modular debugging (kinetics vs regulation)

MATHEMATICAL FORMULATION:
=========================

Classical Inhibitor Arc Enabling:
----------------------------------
enabled(t) iff M(p) < Δ    where Δ ∈ ℝ (constant)

SHYpn Flexible Threshold Function:
-----------------------------------
enabled(t) iff M(p) < Δ(M(p))    where Δ: ℝ → ℝ (function)

Hill Inhibition Threshold Function:
------------------------------------
Δ_Hill([ATP]) = K_i · (1 + ([ATP]/K_i)^n)^(-1/n)

where:
- K_i = inhibition constant (2.5 mM for PFK)
- n = Hill coefficient (4 for cooperative binding)
- [ATP] = current ATP concentration

This encodes cooperative allosteric inhibition directly on the arc.

BIOLOGICAL JUSTIFICATION:
=========================

Allosteric Regulation Reality:
-------------------------------
PFK has TWO types of ATP binding sites:
1. Catalytic site: accepts ATP as substrate (phosphoryl donor)
2. Regulatory site: senses ATP concentration (allosteric inhibitor)

Classical Modeling Problem:
- Mixes both roles in single rate equation
- Cannot distinguish substrate binding from regulatory sensing
- Single parameter ([ATP]) used for dual purposes

SHYpn Solution:
- Substrate binding: [ATP] in rate law M-M term
- Regulatory sensing: [ATP] in arc threshold function Δ_Hill
- Clear separation mirrors biological reality
- Two distinct mechanisms, two distinct model components

ADVANTAGES SUMMARY:
===================

1. **Topology-Explicit Regulation**
   Arc threshold functions make regulatory architecture visible in network diagram

2. **Simplified Rate Laws**
   Transitions contain only stoichiometric kinetics, not regulatory complexity

3. **Separation of Concerns**
   Kinetic parameters vs regulatory parameters isolated in different components

4. **Modular Modifications**
   Change regulation → edit arc threshold (no transition changes)
   Change kinetics → edit rate law (no arc changes)

5. **Debugging Efficiency**
   Rate law errors vs threshold function errors easily distinguished

6. **Mathematical Analysis**
   Stoichiometric constraints vs regulatory constraints separately analyzable

7. **Biological Accuracy**
   Model structure mirrors biological separation of catalytic vs regulatory sites
