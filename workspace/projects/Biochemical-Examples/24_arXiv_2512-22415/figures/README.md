# Lambda Phage Paper Figures

This directory contains figures from the arXiv:2512.22415 paper on hierarchical preemption in lambda phage.

## Available Figures

### Manuscript Figures (from signal_hierarchy project)

1. **figure1_model_architecture.pdf** - Model Architecture Schematic
   - Hierarchical layer diagram showing UV damage → RecA → CII → CI/Cro cascade
   - 4-layer architecture with signal flow visualization
   - Used as Figure 1 in manuscript

2. **figure2_attractor_landscapes.pdf** - Attractor Landscape Analysis
   - Phase space analysis showing bistable regions
   - CII-RecA state space with attractor basins
   - Main result figure demonstrating hierarchical preemption

3. **figure2_attractor_landscapes_2d.pdf** - 2D Attractor Landscape
   - Simplified 2D projection of attractor basins
   - Clearer visualization of basin boundaries
   - Alternative version of Figure 2

4. **figure2_attractor_landscapes_3d.pdf** - 3D Attractor Landscape
   - Full 3D phase space visualization
   - Shows energy landscape with commitment thresholds
   - Supplementary figure (high detail)

### Paper Simulation Figures (generated by generate_paper_figures.py)

The paper also includes 5 main simulation result figures:

1. **outcome_distributions.pdf** - Lysogenic vs. Lytic Outcome Distributions
   - Pie charts for three conditions: ZERO, ZERO + UV, BALANCED + UV
   - Shows 42:48 → 4:86 shift under UV stress

2. **scatter_plots.pdf** - CI-Cro State Space
   - Bistable attractor basins
   - Trajectory endpoints showing decision outcomes

3. **time_courses.pdf** - Representative Trajectories
   - Lysogenic path (CI dominates)
   - Lytic path (Cro dominates)

4. **rate_symmetry.pdf** - Transcription Rate Functions
   - ZERO vs. BALANCED parameter configurations
   - Hill function symmetry analysis

5. **summary_bars.pdf** - Outcome Statistics
   - Bar charts with statistical comparisons
   - Demonstrates 2× UV signal priority

## Generating Figures

### Attractor Landscape Figures
```bash
cd ../scripts
python generate_attractor_landscape.py      # 3D landscape
python generate_attractor_landscape_2d.py   # 2D projection
```

### Simulation Result Figures
```bash
cd ../scripts
python generate_paper_figures.py
```

This reads from `../data/batch_results/` and generates all simulation PDFs.

## Key Results Visualized

- **RecA Signal Priority:** 2× higher information content than environmental signals
- **UV Override:** 42:48 → 4:86 outcome shift (lysogenic → lytic)
- **Hierarchical Architecture:** Layer 1 (RecA) preempts Layer 0 (ATP, metabolic)
- **Basin Geometry:** Phase space structure reveals decision mechanism

- High-resolution PDFs (300+ DPI) suitable for publication
