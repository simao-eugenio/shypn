# Vibrio fischeri Quorum Sensing Figures

This directory contains figures from arXiv:2601.00036 demonstrating the unified signal hierarchy formalism.

## Available Figures

### 1. Formalism Unification Diagram ⭐
**File:** `vfischeri_formalism_unified.pdf`

**Description:** Comprehensive schematic showing the 13-tuple formalism integration with V. fischeri biological system.

**Key Components:**
- Signal place (Ψ): AHL (autoinducer)
- Signal flow arcs (Fₛ): AHL consumption during commitment
- Test arcs (Fₜ): LuxR catalysis (non-consuming)
- Normal arcs (F): Mass transfer (LuxI, luminescence substrates)
- Hierarchical layers (λ): Environmental → Integration → Commitment → Execution

**Theoretical Significance:**
- Demonstrates all three arc types in single biological system
- Shows dual role of AHL: metabolite (synthesized) + signal (regulatory)
- Validates consumption semantics for population-level coordination

## Generating Figures

Figures can be regenerated by running:

```bash
cd ..
python scripts/vfischeri_quorum_sensing.py \
    --cells 1e8 \
    --time 600 \
    --trajectories 5 \
    --output figures/
```

This creates:
- `quorum_sensing_dynamics.png` - Main 4-panel plot
- `quorum_sensing_dynamics.pdf` - Publication-quality vector format
