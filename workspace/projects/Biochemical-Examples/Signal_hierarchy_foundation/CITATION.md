# How to Cite This Work

## Manuscript Citation

If you use this work in your research, please cite:

```bibtex
@article{simao2026signal,
  title={Signal Hierarchy Theory for Biological Petri Nets: Formal Semantics of Hierarchical Regulatory Control},
  author={Sim{\~a}o, Eug{\'e}nio},
  journal={PLOS Computational Biology},
  year={2026},
  note={Submitted January 2026},
  url={https://github.com/simao-eugenio/shypn/tree/main/workspace/projects/Biochemical-Examples/Signal_hierarchy_foundation}
}
```

## Software Citation

If you use the SHYPN software:

```bibtex
@software{simao2026shypn,
  title={SHYPN: Signal Hierarchical Petri Nets for Systems Biology},
  author={Sim{\~a}o, Eug{\'e}nio},
  year={2026},
  url={https://github.com/simao-eugenio/shypn},
  license={MIT}
}
```
