\hypertarget{classical-petri-net-review}{%
\section{4.1 Classical Petri Net
Review}\label{classical-petri-net-review}}

\hypertarget{basic-definitions}{%
\subsection{4.1.1 Basic Definitions}\label{basic-definitions}}

A \textbf{classical Petri net} is a 5-tuple:

\begin{lstlisting}
PN = (P, T, F, W, M₀)
\end{lstlisting}

Where: - \textbf{P} = \{p₁, p₂, \ldots, pₘ\} is a finite set of
\textbf{places} (represented as circles) - \textbf{T} = \{t₁, t₂,
\ldots, tₙ\} is a finite set of \textbf{transitions} (represented as
rectangles or bars) - \textbf{F ⊆ (P × T) ∪ (T × P)} is the \textbf{flow
relation} (directed arcs) - \textbf{W: F \textrightarrow ℕ⁺} is the \textbf{arc weight
function} (positive integers, default W = 1) - \textbf{M₀: P \textrightarrow ℕ₀} is
the \textbf{initial marking} (token distribution)

With the constraint: \textbf{P ∩ T = ∅} (places and transitions are
disjoint)

\hypertarget{neighborhood-notation}{%
\subsection{4.1.2 Neighborhood Notation}\label{neighborhood-notation}}

For a transition t ∈ T: - \textbf{•t} = \{p ∈ P \textbar{} (p,t) ∈ F\} :
\textbf{preset} (input places) - \textbf{t•} = \{p ∈ P \textbar{} (t,p)
∈ F\} : \textbf{postset} (output places)

For a place p ∈ P: - \textbf{•p} = \{t ∈ T \textbar{} (t,p) ∈ F\} :
transitions producing tokens in p - \textbf{p•} = \{t ∈ T \textbar{}
(p,t) ∈ F\} : transitions consuming tokens from p

\hypertarget{enabling-rule}{%
\subsection{4.1.3 Enabling Rule}\label{enabling-rule}}

A transition \textbf{t is enabled} at marking M, written
\textbf{M{[}t⟩}, if and only if:

\begin{lstlisting}
∀p ∈ •t: M(p) ≥ W(p,t)
\end{lstlisting}

All input places must contain at least W(p,t) tokens.

\hypertarget{firing-rule}{%
\subsection{4.1.4 Firing Rule}\label{firing-rule}}

When enabled transition t fires, the new marking M' is computed as:

\begin{lstlisting}
∀p ∈ P: M'(p) = M(p) - W(p,t) + W(t,p)
\end{lstlisting}

Where: - \textbf{W(p,t) = 0} if (p,t) ∉ F (no arc from p to t) -
\textbf{W(t,p) = 0} if (t,p) ∉ F (no arc from t to p)

\textbf{Notation}: M{[}t⟩M' denotes ``transition t is enabled at M and
produces M'''

\hypertarget{reachability}{%
\subsection{4.1.5 Reachability}\label{reachability}}

The \textbf{reachability set} R(M₀) is the set of all markings reachable
from M₀:

\begin{lstlisting}
R(M₀) = {M | ∃σ = t₁t₂...tₖ: M₀[σ⟩M}
\end{lstlisting}

Where σ is a \textbf{firing sequence} of transitions.

\hypertarget{limitations-for-biological-modeling}{%
\subsection{4.1.6 Limitations for Biological
Modeling}\label{limitations-for-biological-modeling}}

Classical Petri nets face fundamental limitations when modeling
biological systems:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{All arcs are consumptive}: Tokens are always removed from
  input places

  \begin{itemize}
  \tightlist
  \item
    \textbf{Problem}: Enzymes catalyze reactions without being consumed
  \item
    \textbf{Example}: Hexokinase phosphorylates glucose but remains
    unchanged
  \item
    If modeled with normal arcs: Enzyme would deplete after first
    reaction
  \end{itemize}
\item
  \textbf{No regulatory inhibition}: Transitions fire whenever inputs
  are available

  \begin{itemize}
  \tightlist
  \item
    \textbf{Problem}: Biological reactions can be blocked by inhibitors
  \item
    \textbf{Example}: High ATP inhibits phosphofructokinase (energy
    feedback)
  \item
    Classical PNs cannot express threshold-based blocking
  \end{itemize}
\item
  \textbf{Strong independence requirement}: Parallel execution requires
  disjoint neighborhoods

  \begin{itemize}
  \tightlist
  \item
    \textbf{Problem}: Biological reactions share places (metabolites,
    enzymes)
  \item
    \textbf{Example}: Multiple reactions produce same metabolite
    (superposition)
  \item
    Classical parallelism rejects most biological networks
  \end{itemize}
\item
  \textbf{Homogeneous transitions}: All transitions follow same firing
  semantics

  \begin{itemize}
  \tightlist
  \item
    \textbf{Problem}: Biology exhibits multiple temporal scales
  \item
    \textbf{Example}: Enzyme kinetics (continuous) vs gene expression
    (stochastic bursts)
  \item
    Classical PNs cannot mix continuous and discrete dynamics natively
  \end{itemize}
\item
  \textbf{Abstract tokens}: No semantic meaning beyond quantity

  \begin{itemize}
  \tightlist
  \item
    \textbf{Problem}: Biochemistry requires elemental composition
    tracking
  \item
    \textbf{Example}: C₆H₁₂O₆ + ATP \textrightarrow C₆H₁₁O₉P + ADP (atoms must
    balance)
  \item
    Classical PNs cannot validate stoichiometric correctness
  \end{itemize}
\end{enumerate}

These limitations motivate the \textbf{Extended Biological Petri Net}
formalism presented in this chapter.

\hypertarget{extended-bio-pn-the-12-tuple-definition}{%
\section{4.2 Extended Bio-PN: The 12-Tuple
Definition}\label{extended-bio-pn-the-12-tuple-definition}}

An \textbf{Extended Biological Petri Net} is a 12-tuple:

\begin{lstlisting}
BioPN = (P, T, F, W, M₀, K, Φ, Σ, Θ, Δ, τ, ρ)
\end{lstlisting}

\hypertarget{core-components-from-classical-pn}{%
\subsection{4.2.1 Core Components (From Classical
PN)}\label{core-components-from-classical-pn}}

\textbf{P: Places} (Biochemical Species) - Metabolites: Glucose, ATP,
NAD⁺, Pyruvate - Enzymes: Hexokinase, Phosphofructokinase, Pyruvate
Kinase - Genes: lacZ, lacY, lacA (structural genes) - Transcription
Factors: CRP, cAMP-CRP complex, LacI repressor - mRNA: lacZ\_mRNA,
lacY\_mRNA - Proteins: β-galactosidase, Permease, Transacetylase

Each place p has attributes: - \textbf{p.id}: Unique identifier (e.g.,
``P001'') - \textbf{p.name}: Human-readable name (e.g., ``Glucose'',
``ATP'') - \textbf{p.formula}: Biochemical formula (e.g., ``C6H12O6'',
``C10H16N5O13P3'') - \textbf{p.type}: \{metabolite, enzyme, gene, mRNA,
protein, complex\}

\textbf{T: Transitions} (Biochemical Reactions) - Enzymatic reactions:
Hexokinase, PGI, PFK, Aldolase, etc. - Transcription: Gene \textrightarrow mRNA -
Translation: mRNA \textrightarrow Protein - Complex formation: cAMP + CRP \textrightarrow cAMP-CRP -
Degradation: mRNA \textrightarrow ∅, Protein \textrightarrow ∅

Each transition t has attributes: - \textbf{t.id}: Unique identifier
(e.g., ``T001'') - \textbf{t.name}: Reaction name (e.g., ``Hexokinase'',
``lacZ\_transcription'') - \textbf{t.ec\_number}: Enzyme Commission
number (e.g., ``2.7.1.1'' for hexokinase) - \textbf{t.reversible}:
Boolean (true for reversible reactions)

\textbf{F ⊆ (P × T) ∪ (T × P): Normal Arcs} (Consumption/Production) -
Directed arcs representing stoichiometric flow - (p,t) ∈ F: place p is
substrate (consumed by t) - (t,p) ∈ F: place p is product (produced by
t)

\textbf{W: F \textrightarrow ℕ⁺: Arc Weights} (Stoichiometric Coefficients) - W(p,t) =
number of tokens consumed from p when t fires - W(t,p) = number of
tokens produced in p when t fires - Default: W = 1 (one molecule
consumed/produced) - Example: Hexokinase consumes 1 Glucose + 1 ATP,
produces 1 G6P + 1 ADP

\textbf{M₀: P \textrightarrow ℕ₀ ∪ ℝ₀⁺: Initial Marking} - Discrete (ℕ₀): Integer
token counts for stochastic models - Example: M₀(Glucose) = 1000
molecules - Continuous (ℝ₀⁺): Real-valued concentrations for ODE models
- Example: M₀(Glucose) = 5.0 mM (millimolar) - Hybrid: Some places
discrete, others continuous - Metabolites: Continuous (high copy number)
- Genes: Discrete (low copy number, typically 1 or 2)

\hypertarget{capacity-constraint}{%
\subsection{4.2.2 Capacity Constraint}\label{capacity-constraint}}

\textbf{K: P \textrightarrow ℕ ∪ \{∞\}: Place Capacity} - Maximum number of tokens
allowed in place p - K(p) = ∞: unbounded (default) - K(p) \textless{} ∞:
bounded (e.g., limited enzyme concentration) - Biological
interpretation: Spatial constraints, crowding effects - Firing rule
modified: t can fire only if M'(p) ≤ K(p) for all p ∈ t•

\hypertarget{rate-functions}{%
\subsection{4.2.3 Rate Functions}\label{rate-functions}}

\textbf{Φ: T \textrightarrow RateFunction: Kinetic Rate Assignment}

Associates each transition with a mathematical function describing its
firing rate.

\textbf{For continuous transitions} (τ(t) = Continuous):

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Mass Action Kinetics}:

\begin{lstlisting}
Φ(t) = k · ∏(M(p) for p ∈ •t)
\end{lstlisting}

  \begin{itemize}
  \tightlist
  \item
    k: rate constant (units: {[}conc{]}¹⁻ⁿ · {[}time{]}⁻¹, n =
    \textbar•t\textbar)
  \item
    Example: A + B \textrightarrow C, Φ = k·{[}A{]}·{[}B{]}
  \end{itemize}
\item
  \textbf{Michaelis-Menten Kinetics} (single substrate):

\begin{lstlisting}
Φ(t) = (Vmax · [S]) / (Km + [S])
\end{lstlisting}

  \begin{itemize}
  \tightlist
  \item
    Vmax: maximum velocity
  \item
    Km: Michaelis constant (substrate concentration at half Vmax)
  \item
  \end{itemize}
\item
  \textbf{Multi-Substrate Michaelis-Menten}:

\begin{lstlisting}
Φ(t) = (Vmax · ∏[Si]) / (Km + ∏[Si])
\end{lstlisting}

  \begin{itemize}
  \tightlist
  \item
    Product of all substrate concentrations
  \item
    Example: Hexokinase: Φ = (Vmax · {[}Glucose{]} · {[}ATP{]}) / (Km +
    {[}Glucose{]}·{[}ATP{]})
  \end{itemize}
\item
  \textbf{Hill Equation} (cooperative binding):

\begin{lstlisting}
Φ(t) = (Vmax · [S]ⁿ) / (K₀.₅ⁿ + [S]ⁿ)
\end{lstlisting}

  \begin{itemize}
  \tightlist
  \item
    n: Hill coefficient (cooperativity, n \textgreater{} 1 positive, n
    \textless{} 1 negative)
  \item
    K₀.₅: concentration at half-maximal activity
  \item
    Example: Hemoglobin oxygen binding (n ≈ 2.8)
  \end{itemize}
\end{enumerate}

\textbf{For stochastic transitions} (τ(t) = Stochastic):

\textbf{Propensity function} (Gillespie algorithm):

\begin{lstlisting}
a(t) = k · ∏(M(p) for p ∈ •t ∪ Σ(t))
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  Includes both input places (•t) and test arc places (Σ(t))
\item
  Stochastic rate constant k (units: {[}time{]}⁻¹)
\item
  Example: Gene transcription a = k\_transcription · M(gene) ·
  M(polymerase)
\end{itemize}

\textbf{For timed transitions} (τ(t) = Timed):

\begin{lstlisting}
Φ(t) = Delay(τ_delay)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  Deterministic delay τ\_delay
\item
  Example: Cell cycle checkpoint (fires exactly 30 minutes after
  enabling)
\end{itemize}

\textbf{For burst transitions} (τ(t) = Burst):

\begin{lstlisting}
Φ(t) = Burst(λ_burst, μ_size)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  λ\_burst: inter-burst interval rate (exponential distribution)
\item
  μ\_size: burst size (geometric distribution)
\item
  Example: mRNA transcriptional bursts
\end{itemize}

\hypertarget{test-arcs-catalysis}{%
\subsection{4.2.4 Test Arcs (Catalysis)}\label{test-arcs-catalysis}}

\textbf{Σ ⊆ P × T: Test Arcs} (Read-Only, Non-Consumptive)

Test arcs enable transitions without consuming tokens.

\textbf{Semantics}: - (p,t) ∈ Σ: place p is a \textbf{catalyst} for
transition t - \textbf{Pre-condition}: M(p) \textgreater{} 0 (catalyst
must be present) - \textbf{Post-condition}: M'(p) = M(p) (catalyst
unchanged after firing)

\textbf{Biological Interpretation}: 1. \textbf{Enzymes}: Catalyze
reactions without being consumed - Example: Hexokinase (enzyme) ⤏
Hexokinase\_reaction - M(Hexokinase) remains constant

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\setcounter{enumi}{1}
\tightlist
\item
  \textbf{Transcription Factors}: Regulate gene expression without
  degradation

  \begin{itemize}
  \tightlist
  \item
    Example: cAMP-CRP ⤏ lacZ\_transcription
  \item
    cAMP-CRP enables transcription but is not consumed
  \end{itemize}
\item
  \textbf{Ribosomes}: Catalyze translation without being consumed

  \begin{itemize}
  \tightlist
  \item
    Example: Ribosome ⤏ Translation\_lacZ
  \item
    Ribosome reads mRNA, produces protein, remains free
  \end{itemize}
\end{enumerate}

\textbf{Formal Constraint}:

\begin{lstlisting}
Σ ∩ F = ∅  (test arcs and normal arcs are disjoint)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  A place cannot be both substrate (consumed) and catalyst
  (non-consumptive) for the same transition
\end{itemize}

\textbf{Graphical Notation}: - Dashed arrow: p ⤏ t - Often with hollow
arrowhead to distinguish from normal arcs

\hypertarget{inhibitor-arcs-regulation}{%
\subsection{4.2.5 Inhibitor Arcs
(Regulation)}\label{inhibitor-arcs-regulation}}

\textbf{Θ ⊆ P × T: Inhibitor Arcs} (Threshold-Based Blocking)

Inhibitor arcs block transitions when inhibitor concentration exceeds
threshold.

\textbf{Semantics}: - (p,t) ∈ Θ: place p is an \textbf{inhibitor} of
transition t - \textbf{Pre-condition}: M(p) \textless{} Δ(p,t)
(inhibitor below threshold) - \textbf{Blocking condition}: If M(p) ≥
Δ(p,t), transition t is \textbf{disabled} - \textbf{Post-condition}:
M'(p) = M(p) (inhibitor unchanged after firing)

\textbf{Biological Interpretation}: 1. \textbf{Allosteric Feedback
Inhibition}: - Example: ATP ⊸ PFK (threshold Δ = 5.0 mM) - When M(ATP) ≥
5.0 mM, PFK is inhibited (energy sufficient) - When M(ATP) \textless{}
5.0 mM, PFK is active (energy needed)

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\setcounter{enumi}{1}
\tightlist
\item
  \textbf{Transcriptional Repression}:

  \begin{itemize}
  \tightlist
  \item
    Example: LacI ⊸ lacZ\_transcription (threshold Δ = 1.0 molecules)
  \item
    When M(LacI) ≥ 1.0, lacZ transcription blocked (repressor bound)
  \item
    When M(LacI) \textless{} 1.0, lacZ transcription allowed (repressor
    absent)
  \end{itemize}
\item
  \textbf{Competitive Inhibition}:

  \begin{itemize}
  \tightlist
  \item
    Example: Glucose ⊸ Lactose\_uptake (threshold Δ = 0.1 mM)
  \item
    High glucose blocks lactose metabolism (catabolite repression)
  \end{itemize}
\end{enumerate}

\textbf{Formal Constraint}:

\begin{lstlisting}
Θ ∩ F = ∅  and  Θ ∩ Σ = ∅
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  Inhibitor arcs are disjoint from normal arcs and test arcs
\item
  A place cannot be substrate, catalyst, AND inhibitor for same
  transition
\end{itemize}

\textbf{Graphical Notation}: - Circle-headed arrow: p ⊸ t - Often
annotated with threshold value Δ(p,t)

\hypertarget{inhibition-threshold-functions}{%
\subsection{4.2.6 Inhibition Threshold
Functions}\label{inhibition-threshold-functions}}

\textbf{Δ: Θ \textrightarrow ThresholdFormula: Inhibition Threshold}

Maps each inhibitor arc to a threshold formula or value.

\textbf{Simple Threshold} (constant):

\begin{lstlisting}
Δ(p,t) = θ ∈ ℝ⁺
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  Transition t is disabled if M(p) ≥ θ
\item
  Example: Δ(ATP, PFK) = 5.0 mM
\end{itemize}

\textbf{Dynamic Threshold} (formula):

\begin{lstlisting}
Δ(p,t) = f(M) : (P \textrightarrow ℝ₀⁺) \textrightarrow ℝ⁺
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  Threshold depends on current marking M
\item
  Example: Δ(ATP, PFK) = ``2.0 * M(AMP)'' (relative ATP/AMP ratio)
\end{itemize}

\textbf{Hill Equation} (cooperative inhibition):

\begin{lstlisting}
Δ(p,t) = K₀.₅ⁿ / (K₀.₅ⁿ + M(p)ⁿ)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  K₀.₅: half-inhibitory concentration
\item
  n: Hill coefficient (cooperativity)
\item
  Returns value in {[}0,1{]}, interpreted as ``effective threshold''
\item
  n = 1: Non-cooperative (hyperbolic)
\item
  n \textgreater{} 1: Positive cooperativity (sigmoidal, ultrasensitive)
\item
  n \textless{} 1: Negative cooperativity
\end{itemize}

\textbf{Example} (PFK allosteric inhibition by ATP):

\begin{lstlisting}
Δ(ATP, PFK) = 5.0⁴ / (5.0⁴ + M(ATP)⁴)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  K₀.₅ = 5.0 mM, n = 4 (highly cooperative)
\item
  When M(ATP) = 2.0 mM: Δ ≈ 0.975 (almost no inhibition)
\item
  When M(ATP) = 5.0 mM: Δ = 0.5 (half-maximal inhibition)
\item
  When M(ATP) = 10.0 mM: Δ ≈ 0.06 (strong inhibition)
\end{itemize}

\textbf{Implementation Note}: Threshold formulas are stored as strings
and evaluated at runtime:

\begin{lstlisting}[language=Python]
threshold_formula = "5.0**4 / (5.0**4 + M_ATP**4)"
delta_value = eval(threshold_formula, {"M_ATP": current_marking["ATP"]})
if current_marking["ATP"] >= delta_value:
    transition_enabled = False
\end{lstlisting}

\hypertarget{transition-type-classification}{%
\subsection{4.2.7 Transition Type
Classification}\label{transition-type-classification}}

\textbf{τ: T \textrightarrow \{Continuous, Stochastic, Timed, Burst\}: Transition
Type}

Assigns each transition to one of four execution modes.

\textbf{1. Continuous Transitions} (τ(t) = Continuous) -
\textbf{Semantics}: Ordinary Differential Equations (ODE) -
\textbf{Dynamics}: dM/dt = Φ(t, M) - \textbf{Rate}: Real-valued,
positive (e.g., 0.5 mM/s) - \textbf{Time}: Continuous, smooth evolution
- \textbf{Integration}: Euler, Runge-Kutta, adaptive step size -
\textbf{Biological Examples}: - Enzyme-catalyzed reactions
(Michaelis-Menten) - Metabolic fluxes (glycolysis, TCA cycle) - Fast
protein-protein interactions

\textbf{2. Stochastic Transitions} (τ(t) = Stochastic) -
\textbf{Semantics}: Gillespie Stochastic Simulation Algorithm (SSA) -
\textbf{Dynamics}: Discrete events, exponentially distributed
inter-event times - \textbf{Propensity}: a(t) = k · ∏M(p) -
\textbf{Time}: Continuous, but fires at discrete time points -
\textbf{Algorithm}: 1. Compute propensities a(t) for all enabled
transitions 2. Total propensity: a₀ = Σa(t) 3. Time to next event: τ
\textasciitilde{} Exp(a₀) 4. Select transition with probability a(t)/a₀
- \textbf{Biological Examples}: - Gene transcription (low copy number) -
Gene translation (mRNA \textrightarrow protein) - Binding/unbinding events (TF + DNA)
- Degradation (mRNA decay, protein degradation)

\textbf{3. Timed Transitions} (τ(t) = Timed) - \textbf{Semantics}:
Deterministic delay - \textbf{Dynamics}: Fires exactly τ\_delay time
units after becoming enabled - \textbf{Delay}: Fixed duration (e.g., 30
minutes) - \textbf{Time}: Scheduled, predictable - \textbf{Biological
Examples}: - Cell cycle checkpoints (G1/S, G2/M transitions) - Circadian
rhythm oscillations (24-hour period) - Developmental stages (timed
differentiation)

\textbf{4. Burst Transitions} (τ(t) = Burst) - \textbf{Semantics}:
Random bursts with two-parameter model - \textbf{Inter-burst interval}:
Exponentially distributed, rate λ\_burst - \textbf{Burst size}:
Geometrically distributed, mean μ\_size - \textbf{Time}: Discrete bursts
at random times - \textbf{Biological Examples}: - Transcriptional
bursting (mRNA produced in pulses) - Promoter switching (ON/OFF states)
- Bursty protein production

\textbf{Heterogeneity}: A single model can contain transitions of all
four types simultaneously. This enables \textbf{multi-scale temporal
modeling}: - Fast reactions (continuous, milliseconds to seconds) -
Medium reactions (stochastic, seconds to minutes) - Slow reactions
(timed, minutes to hours) - Pulsatile events (burst, irregular)

\textbf{Example} (Energy Sensing Motif):

\begin{lstlisting}
τ(PFK_reaction) = Continuous         # Enzyme kinetics (fast)
τ(PK_reaction) = Continuous          # Enzyme kinetics (fast)
τ(PFK_gene_transcription) = Burst   # mRNA bursts (slow, pulsatile)
τ(PFK_mRNA_translation) = Stochastic # Protein synthesis (medium)
τ(Cell_division) = Timed             # Fixed 90-minute cycle
\end{lstlisting}

\hypertarget{biochemical-reaction-formulas}{%
\subsection{4.2.8 Biochemical Reaction
Formulas}\label{biochemical-reaction-formulas}}

\textbf{ρ: T \textrightarrow BiochemicalFormula: Stoichiometry with Elemental
Composition}

Maps each transition to a reaction formula specifying elemental
composition.

\textbf{Format}:

\begin{lstlisting}
ρ(t) = "reactant1 + reactant2 + ... \textrightarrow product1 + product2 + ..."
\end{lstlisting}

Where each reactant/product is a biochemical formula (e.g., C6H12O6).

\textbf{Example} (Hexokinase):

\begin{lstlisting}
ρ(Hexokinase) = "C6H12O6 + C10H16N5O13P3 \textrightarrow C6H11O9P + C10H16N5O10P2 + H"
\end{lstlisting}

Expands to: Glucose + ATP \textrightarrow Glucose-6-phosphate + ADP + H⁺

\textbf{Elemental Decomposition}: Each formula is parsed into elemental
counts:

\begin{lstlisting}
Glucose:     C6H12O6      \textrightarrow {C: 6, H: 12, O: 6}
ATP:         C10H16N5O13P3 \textrightarrow {C: 10, H: 16, N: 5, O: 13, P: 3}
G6P:         C6H11O9P     \textrightarrow {C: 6, H: 11, O: 9, P: 1}
ADP:         C10H16N5O10P2 \textrightarrow {C: 10, H: 16, N: 5, O: 10, P: 2}
H⁺:          H            \textrightarrow {H: 1}
\end{lstlisting}

\textbf{Elemental Balance Check}: For each element e ∈ \{C, H, O, N, P,
S\}:

\begin{lstlisting}
Σ(atoms[e] in reactants) = Σ(atoms[e] in products)
\end{lstlisting}

For hexokinase: - Carbon: 6 + 10 = 16 (left), 6 + 10 = 16 (right) \checkmark -
Hydrogen: 12 + 16 = 28 (left), 11 + 16 + 1 = 28 (right) \checkmark - Oxygen: 6 +
13 = 19 (left), 9 + 10 = 19 (right) \checkmark - Nitrogen: 0 + 5 = 5 (left), 0 +
5 = 5 (right) \checkmark - Phosphorus: 0 + 3 = 3 (left), 1 + 2 = 3 (right) \checkmark

\textbf{If unbalanced}: Flag as \textbf{stoichiometry error}

\textbf{Elemental Balance Matrix} S\_e: - Rows: Transitions t ∈ T -
Columns: Elements e ∈ \{C, H, O, N, P, S\} - Entry S\_e{[}t,e{]}: Net
element change for transition t
\passthrough{\lstinline!S\_e[t,e] = Σ(atoms[e] in products) - Σ(atoms[e] in reactants)!}
- \textbf{Well-balanced network}: S\_e{[}t,e{]} = 0 for all t, e

\textbf{Source/Sink Detection}: - \textbf{Elemental source}: Transition
t where S\_e{[}t,e{]} \textgreater{} 0 (creates atoms) -
\textbf{Elemental sink}: Transition t where S\_e{[}t,e{]} \textless{} 0
(destroys atoms) - \textbf{Valid}: Transport across system boundary
(import/export) - \textbf{Invalid}: Internal reaction violates
conservation laws

\hypertarget{arc-type-semantics-and-firing-rules}{%
\section{4.3 Arc Type Semantics and Firing
Rules}\label{arc-type-semantics-and-firing-rules}}

\hypertarget{composite-enabling-condition}{%
\subsection{4.3.1 Composite Enabling
Condition}\label{composite-enabling-condition}}

A transition \textbf{t is enabled} at marking M if and only if
\textbf{ALL} of the following hold:

\textbf{Condition 1}: \textbf{Normal arcs} (substrates available)

\begin{lstlisting}
∀p ∈ •t: M(p) ≥ W(p,t)
\end{lstlisting}

All input places have sufficient tokens.

\textbf{Condition 2}: \textbf{Test arcs} (catalysts present)

\begin{lstlisting}
∀(p,t) ∈ Σ: M(p) > 0
\end{lstlisting}

All catalyst places are non-empty.

\textbf{Condition 3}: \textbf{Inhibitor arcs} (inhibitors below
threshold)

\begin{lstlisting}
∀(p,t) ∈ Θ: M(p) < Δ(p,t)
\end{lstlisting}

All inhibitor places are below their respective thresholds.

\textbf{Condition 4}: \textbf{Capacity constraint} (outputs not full)

\begin{lstlisting}
∀p ∈ t•: M(p) + W(t,p) ≤ K(p)
\end{lstlisting}

Firing would not exceed place capacities.

\textbf{Notation}: \textbf{M{[}t⟩} means ``transition t is enabled at
marking M''

\hypertarget{firing-semantics-by-arc-type}{%
\subsection{4.3.2 Firing Semantics by Arc
Type}\label{firing-semantics-by-arc-type}}

When enabled transition t fires (M{[}t⟩M'), the new marking M' is
computed as follows:

\textbf{Normal arcs} (F):

\begin{lstlisting}
If (p,t) ∈ F: M'(p) = M(p) - W(p,t)    # Consume tokens
If (t,p) ∈ F: M'(p) = M(p) + W(t,p)    # Produce tokens
\end{lstlisting}

\textbf{Test arcs} (Σ):

\begin{lstlisting}
If (p,t) ∈ Σ: M'(p) = M(p)             # Unchanged (read-only)
\end{lstlisting}

\textbf{Inhibitor arcs} (Θ):

\begin{lstlisting}
If (p,t) ∈ Θ: M'(p) = M(p)             # Unchanged (regulation only)
\end{lstlisting}

\textbf{All other places}:

\begin{lstlisting}
M'(p) = M(p)                            # Unchanged
\end{lstlisting}

\textbf{Summary}: Only places connected by \textbf{normal arcs} change
their marking. Test arcs and inhibitor arcs are
\textbf{non-consumptive}.

\hypertarget{firing-semantics-by-transition-type}{%
\subsection{4.3.3 Firing Semantics by Transition
Type}\label{firing-semantics-by-transition-type}}

\textbf{Continuous transitions} (τ(t) = Continuous): -
\textbf{Dynamics}: dM/dt = Φ(t, M) · (consumption and production
vectors) - \textbf{Interpretation}: Rate of change proportional to rate
function - \textbf{Example}: dM(Glucose)/dt = -Φ(Hexokinase) (glucose
consumed)

\textbf{Stochastic transitions} (τ(t) = Stochastic): -
\textbf{Dynamics}: Discrete firing at exponentially distributed times -
\textbf{Inter-event time}: τ \textasciitilde{} Exp(a(t)) -
\textbf{Tokens updated}: Instantaneous change (M \textrightarrow M')

\textbf{Timed transitions} (τ(t) = Timed): - \textbf{Dynamics}: Fires
exactly Delay(τ\_delay) after becoming enabled - \textbf{Example}: G1/S
checkpoint fires 30 minutes after conditions met

\textbf{Burst transitions} (τ(t) = Burst): - \textbf{Dynamics}:
Exponential inter-burst interval, geometric burst size - \textbf{Tokens
updated}: Batch production (e.g., 5 mRNA molecules at once)

\hypertarget{example-hexokinase-reaction}{%
\subsection{4.3.4 Example: Hexokinase
Reaction}\label{example-hexokinase-reaction}}

\textbf{Biological reaction}:

\begin{lstlisting}
Glucose + ATP --[Hexokinase]--> Glucose-6-phosphate + ADP
\end{lstlisting}

\textbf{Extended Bio-PN representation}:

\begin{lstlisting}
Places:
  P1: Glucose (C6H12O6), M₀ = 5.0 mM
  P2: ATP (C10H16N5O13P3), M₀ = 2.5 mM
  P3: Glucose-6-phosphate (C6H11O9P), M₀ = 0.0 mM
  P4: ADP (C10H16N5O10P2), M₀ = 0.5 mM
  P5: Hexokinase (enzyme), M₀ = 0.1 mM

Transition:
  T1: Hexokinase_reaction
  τ(T1) = Continuous
  Φ(T1) = (Vmax · [Glucose] · [ATP]) / (Km + [Glucose]·[ATP])
    where Vmax = 70 mM/s, Km = 0.1 mM²

Arcs:
  Normal arcs (F):
    (P1, T1) with W = 1  # Glucose consumed
    (P2, T1) with W = 1  # ATP consumed
    (T1, P3) with W = 1  # G6P produced
    (T1, P4) with W = 1  # ADP produced
  
  Test arc (Σ):
    (P5, T1)  # Hexokinase catalyzes (not consumed)

Biochemical formula:
  ρ(T1) = "C6H12O6 + C10H16N5O13P3 \textrightarrow C6H11O9P + C10H16N5O10P2 + H"
\end{lstlisting}

\textbf{Enabling condition}:

\begin{lstlisting}
M(Glucose) ≥ 1  AND  M(ATP) ≥ 1  AND  M(Hexokinase) > 0
\end{lstlisting}

\textbf{Firing} (continuous semantics):

\begin{lstlisting}
dM(Glucose)/dt = -Φ(T1)
dM(ATP)/dt = -Φ(T1)
dM(G6P)/dt = +Φ(T1)
dM(ADP)/dt = +Φ(T1)
dM(Hexokinase)/dt = 0  # Enzyme conserved
\end{lstlisting}

\textbf{Elemental balance}: - C: 6 + 10 = 6 + 10 \checkmark - H: 12 + 16 = 11 +
16 + 1 \checkmark - O: 6 + 13 = 9 + 10 \checkmark - N: 5 = 5 \checkmark - P: 3 = 1 + 2 \checkmark

\hypertarget{example-pfk-with-atp-feedback-inhibition}{%
\subsection{4.3.5 Example: PFK with ATP Feedback
Inhibition}\label{example-pfk-with-atp-feedback-inhibition}}

\textbf{Biological reaction}:

\begin{lstlisting}
Fructose-6-phosphate + ATP --[PFK]--> Fructose-1,6-bisphosphate + ADP
  (Inhibited by high ATP via allosteric site)
\end{lstlisting}

\textbf{Extended Bio-PN representation}:

\begin{lstlisting}
Places:
  P1: Fructose-6-phosphate (F6P), M₀ = 2.0 mM
  P2: ATP, M₀ = 3.0 mM
  P3: Fructose-1,6-bisphosphate (F-1,6-BP), M₀ = 0.5 mM
  P4: ADP, M₀ = 1.0 mM
  P5: PFK (enzyme), M₀ = 0.05 mM

Transition:
  T1: PFK_reaction
  τ(T1) = Continuous
  Φ(T1) = (Vmax · [F6P] · [ATP]) / (Km + [F6P]·[ATP])
    where Vmax = 90 mM/s, Km = 0.2 mM²

Arcs:
  Normal arcs (F):
    (P1, T1) with W = 1  # F6P consumed
    (P2, T1) with W = 1  # ATP consumed (catalytic site)
    (T1, P3) with W = 1  # F-1,6-BP produced
    (T1, P4) with W = 1  # ADP produced
  
  Test arc (Σ):
    (P5, T1)  # PFK enzyme catalyzes
  
  Inhibitor arc (Θ):
    (P2, T1)  # ATP inhibits (allosteric site)
    Δ(P2, T1) = 5.0⁴ / (5.0⁴ + M(ATP)⁴)  # Hill equation, K₀.₅=5.0 mM, n=4

Biochemical formula:
  ρ(T1) = "C6H10O9P + C10H16N5O13P3 \textrightarrow C6H10O12P2 + C10H16N5O10P2 + H"
\end{lstlisting}

\textbf{Enabling condition}:

\begin{lstlisting}
M(F6P) ≥ 1  AND  M(ATP) ≥ 1  AND  M(PFK) > 0  AND  M(ATP) < Δ(ATP, PFK)
\end{lstlisting}

\textbf{Scenarios}:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Low ATP} (M(ATP) = 2.0 mM):

\begin{lstlisting}
Δ(ATP, PFK) = 5.0⁴/(5.0⁴+2.0⁴) = 625/(625+16) ≈ 0.975
M(ATP) = 2.0 < 0.975? NO (wait, this is normalized)

Correct interpretation:
Inhibition strength = M(ATP)⁴/(5.0⁴ + M(ATP)⁴) = 16/641 ≈ 0.025 (2.5% inhibited)
\textrightarrow PFK is ACTIVE (97.5% activity)
\end{lstlisting}
\item
  \textbf{Medium ATP} (M(ATP) = 5.0 mM):

\begin{lstlisting}
Inhibition strength = 5.0⁴/(5.0⁴ + 5.0⁴) = 0.5 (50% inhibited)
\textrightarrow PFK is MODERATELY ACTIVE (50% activity)
\end{lstlisting}
\item
  \textbf{High ATP} (M(ATP) = 10.0 mM):

\begin{lstlisting}
Inhibition strength = 10.0⁴/(5.0⁴ + 10.0⁴) = 10000/10625 ≈ 0.941 (94% inhibited)
\textrightarrow PFK is INHIBITED (6% activity remaining)
\end{lstlisting}
\end{enumerate}

\textbf{Biological interpretation}: - When energy is LOW (ATP
\textless{} 5 mM): Glycolysis proceeds (PFK active, produce more ATP) -
When energy is HIGH (ATP \textgreater{} 5 mM): Glycolysis slows (PFK
inhibited, conserve glucose)

\hypertarget{well-formedness-constraints}{%
\section{4.4 Well-Formedness
Constraints}\label{well-formedness-constraints}}

An Extended Bio-PN must satisfy the following structural constraints:

\textbf{C1: Disjointness of Arc Types}

\begin{lstlisting}
F ∩ Σ = ∅  AND  F ∩ Θ = ∅  AND  Σ ∩ Θ = ∅
\end{lstlisting}

Arc types are mutually exclusive. A place cannot be simultaneously: -
Substrate (normal arc) and catalyst (test arc) for same transition -
Substrate (normal arc) and inhibitor (inhibitor arc) for same transition
- Catalyst (test arc) and inhibitor (inhibitor arc) for same transition

\textbf{C2: No Self-Loops via Test/Inhibitor Arcs}

\begin{lstlisting}
∀(p,t) ∈ Σ: p ∉ t•  (test arc source not in postset)
∀(p,t) ∈ Θ: p ∉ t•  (inhibitor arc source not in postset)
\end{lstlisting}

Prevents circular dependencies where transition affects its own enabling
condition.

\textbf{C3: Positive Arc Weights}

\begin{lstlisting}
∀f ∈ F: W(f) > 0
\end{lstlisting}

All normal arcs have positive integer weights (stoichiometry must be ≥
1).

\textbf{C4: Positive Thresholds}

\begin{lstlisting}
∀(p,t) ∈ Θ: Δ(p,t) > 0
\end{lstlisting}

All inhibitor thresholds are positive (zero threshold = always
inhibited, meaningless).

\textbf{C5: Non-Negative Initial Marking}

\begin{lstlisting}
∀p ∈ P: M₀(p) ≥ 0
\end{lstlisting}

Token counts and concentrations cannot be negative.

\textbf{C6: Place Capacity Consistency}

\begin{lstlisting}
∀p ∈ P: M₀(p) ≤ K(p)
\end{lstlisting}

Initial marking must respect place capacities.

\textbf{C7: Biochemical Formula Validity}

\begin{lstlisting}
∀t ∈ T: ElementalBalance(ρ(t)) = True
\end{lstlisting}

All reaction formulas must conserve atoms (C, H, O, N, P, S).

\textbf{C8: Rate Function Compatibility}

\begin{lstlisting}
∀t ∈ T: Φ(t) is compatible with τ(t)
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  Continuous transitions: Rate function returns ℝ⁺
\item
  Stochastic transitions: Propensity function returns ℝ⁺
\item
  Timed transitions: Delay function returns ℝ⁺
\item
  Burst transitions: Burst parameters (λ, μ) ∈ ℝ⁺
\end{itemize}

rectangle) - \textbf{▬◷} Timed transition (clock symbol) - \textbf{▬⚡}

``Hexokinase'', ``lacZ\_transcription'')

Consumption/production - Weight label: Integer (e.g., ``2'' for 2 ATP

non-consumptive - \textbf{⊸} Inhibitor arc (circle-headed arrow):
Threshold-based blocking - Threshold label: Value or formula (e.g., ``≥
5.0 mM'' or ``Hill(K=5, n=4)'')

\hypertarget{summary}{%
\section{4.7 Summary}\label{summary}}

The \textbf{Extended Biological Petri Net} formalism extends classical
Petri nets with:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Three arc types}: Normal (consumption), test (catalysis),
  inhibitor (regulation)
\item
  \textbf{Four transition types}: Continuous, stochastic, timed, burst
\item
  \textbf{Biochemical formulas}: Elemental composition tracking
  (C/H/O/N/P/S)
\item
  \textbf{Threshold formulas}: Hill equations, dynamic thresholds on
  inhibitor arcs
\item
  \textbf{Weak independence}: Shared outputs/catalysts allowed
  (cooperativity + parallelism)
\end{enumerate}

These extensions enable: - \checkmark \textbf{Enzyme conservation}: Test arcs
preserve catalyst levels - \checkmark \textbf{Multi-scale dynamics}: Continuous
kinetics + stochastic bursts + timed events - \checkmark
\textbf{Topology-embedded regulation}: Thresholds visible on arcs, not
hidden in code - \checkmark \textbf{Atomic-level validation}: Stoichiometry
checked via elemental balance - \checkmark \textbf{Biological cooperativity}:
Shared places allowed (weak independence theory)

\textbf{Next chapter} (Chapter 5) formalizes \textbf{weak independence
theory}, the primary theoretical contribution enabling parallel
execution with shared places.
