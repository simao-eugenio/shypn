\hypertarget{petri-net-fundamentals}{%
\section{2.1 Petri Net Fundamentals}\label{petri-net-fundamentals}}

\hypertarget{classical-petri-nets}{%
\subsection{2.1.1 Classical Petri Nets}\label{classical-petri-nets}}

\textbf{Petri nets}, introduced by Carl Adam Petri in 1962, are a
mathematical formalism for modeling concurrent systems. A
\textbf{classical Petri net} is a 5-tuple:

\[
PN = (P, T, F, W, M_0)
\]

Where: - \textbf{P}: Finite set of \textbf{places} (circles, represent
conditions or resources) - \textbf{T}: Finite set of
\textbf{transitions} (rectangles, represent events or actions) -
\textbf{F ⊆ (P × T) ∪ (T × P)}: \textbf{Flow relation} (arcs connecting
places to transitions and vice versa) - \textbf{W: F \textrightarrow ℕ⁺}:
\textbf{Weight function} (arc multiplicities, stoichiometric
coefficients) - \textbf{M₀: P \textrightarrow ℕ}: \textbf{Initial marking} (token
distribution at time t=0)

\textbf{Graphical notation}: - \textbf{Places}: Circles containing
tokens (black dots) - \textbf{Transitions}: Rectangles or bars -
\textbf{Arcs}: Arrows with weights (omitted if weight = 1)

\textbf{Example} (Simple chemical reaction A + B \textrightarrow C):

\begin{lstlisting}
   (A)●●     (B)●
    │  ╲    ╱
    │   ╲  ╱
    │    T1
    │   ╱  ╲
    │  ╱    ╲
   (C)       
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  Places: P = \{A, B, C\}
\item
  Transitions: T = \{T1\}
\item
  Arcs: F = \{(A,T1), (B,T1), (T1,C)\}
\item
  Weights: W(A,T1)=1, W(B,T1)=1, W(T1,C)=1
\item
  Initial marking: M₀(A)=2, M₀(B)=1, M₀(C)=0
\end{itemize}

\hypertarget{petri-net-semantics}{%
\subsection{2.1.2 Petri Net Semantics}\label{petri-net-semantics}}

\textbf{Enabling}: Transition t is \textbf{enabled} at marking M if: \[
\forall p \in \bullet t: M(p) \geq W(p,t)
\]

Where \(\bullet t\) denotes the \textbf{preset} (input places) of t.

\textbf{Firing}: When enabled transition t fires: 1. \textbf{Consume
tokens} from input places: \(M'(p) = M(p) - W(p,t)\) for all
\(p \in \bullet t\) 2. \textbf{Produce tokens} at output places:
\(M'(p) = M(p) + W(t,p)\) for all \(p \in t\bullet\)

Where \(t\bullet\) denotes the \textbf{postset} (output places) of t.

\textbf{Example} (A + B \textrightarrow C): - \textbf{Before firing}: M = \{A:2, B:1,
C:0\} - \textbf{T1 enabled?} Yes (M(A)=2 ≥ 1, M(B)=1 ≥ 1) - \textbf{T1
fires}: Consume 1 token from A, 1 from B, produce 1 at C - \textbf{After
firing}: M' = \{A:1, B:0, C:1\}

\hypertarget{petri-net-properties}{%
\subsection{2.1.3 Petri Net Properties}\label{petri-net-properties}}

\textbf{Behavioral properties}: - \textbf{Reachability}: Can marking M'
be reached from M₀? - \textbf{Boundedness}: Is there a maximum token
count per place? - \textbf{Liveness}: Can all transitions eventually
fire? - \textbf{Deadlock-freedom}: Does the net avoid states where no
transition is enabled?

\textbf{Structural properties} (independent of M₀): -
\textbf{P-invariants} (place invariants): Token-conserving sets of
places - Linear combination: \(y^T \cdot M = y^T \cdot M_0\) (constant
sum) - Example: Enzyme conservation (E\_free + E\_bound = constant) -
\textbf{T-invariants} (transition invariants): Firing sequences
returning to same marking - Example: Catalytic cycles (net effect = 0)

\textbf{Complexity}: - \textbf{Reachability}: EXPSPACE-complete
(decidable but computationally hard) - \textbf{Boundedness}:
EXPSPACE-complete - \textbf{Liveness}: EXPSPACE-complete

\hypertarget{limitations-for-biological-modeling}{%
\subsection{2.1.4 Limitations for Biological
Modeling}\label{limitations-for-biological-modeling}}

\textbf{Classical Petri nets have fundamental limitations}:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{No regulatory arcs}: Cannot represent catalysis (enzyme
  unchanged) or inhibition (threshold blocking) without encoding in
  external code
\item
  \textbf{Homogeneous transitions}: All transitions fire instantaneously
  (no continuous kinetics) or all are timed (no stochastic bursts)
\item
  \textbf{Strong independence only}: Parallelism requires disjoint
  neighborhoods (no shared places)
\item
  \textbf{Token abstraction}: Tokens are abstract units (not molecules
  with formulas)
\item
  \textbf{No rate semantics}: Firing frequency is non-deterministic or
  requires external rate assignment
\end{enumerate}

\textbf{These gaps motivate extensions} for systems biology.

\hypertarget{petri-net-extensions}{%
\section{2.2 Petri Net Extensions}\label{petri-net-extensions}}

\hypertarget{colored-petri-nets-cpn}{%
\subsection{2.2.1 Colored Petri Nets
(CPN)}\label{colored-petri-nets-cpn}}

\textbf{Jensen (1981)} introduced \textbf{colored Petri nets} where
tokens have \textbf{data types} (colors): - Places hold
\textbf{multisets of colored tokens} (e.g., \{glucose:5, fructose:2\}) -
Transitions have \textbf{guards} (boolean predicates) and \textbf{arc
expressions} (token transformations) - Enables modeling complex data
structures (proteins with phosphorylation states)

\textbf{Advantages}: - \textbf{Compactness}: One place can represent
multiple species (different colors) - \textbf{Data manipulation}: Arc
expressions compute token transformations

\textbf{Limitations for biology}: - \textbf{Complexity}: Guards and
expressions are code (not visual arcs) - \textbf{Analysis difficulty}:
Structural properties (P-invariants) are harder to compute - \textbf{No
heterogeneous dynamics}: Still lacks native continuous/stochastic/burst
transitions

\hypertarget{timed-petri-nets}{%
\subsection{2.2.2 Timed Petri Nets}\label{timed-petri-nets}}

\textbf{Ramchandani (1974)} added \textbf{time delays} to transitions: -
Transitions fire after a \textbf{deterministic delay} (e.g., 5 seconds)
- Models sequential processes with known durations

\textbf{Merlin (1974)} introduced \textbf{time intervals}: - Transitions
fire within a time window {[}tₘᵢₙ, tₘₐₓ{]} - Non-deterministic timing

\textbf{Limitations}: - \textbf{Still discrete}: No continuous state
evolution (ODEs) - \textbf{Homogeneous}: All transitions timed (cannot
mix with stochastic)

\hypertarget{stochastic-petri-nets-spn}{%
\subsection{2.2.3 Stochastic Petri Nets
(SPN)}\label{stochastic-petri-nets-spn}}

\textbf{Molloy (1981)} introduced \textbf{stochastic Petri nets}: -
Transitions fire after \textbf{exponentially distributed delays} (rate
λ) - Equivalent to continuous-time Markov chains (CTMC) - Enables
performance analysis (throughput, mean response time)

\textbf{Generalized Stochastic Petri Nets (GSPN)} (Ajmone Marsan et al.,
1984): - \textbf{Immediate transitions} (fire instantly, priority 0) -
\textbf{Timed transitions} (exponential delays)

\textbf{Applications to biology}: - \textbf{Gene expression}:
Transcription/translation as stochastic events - \textbf{Molecular
interactions}: Binding/unbinding with rate constants

\textbf{Limitations}: - \textbf{Exponential assumption}: Not all
biological processes are memoryless - \textbf{State space explosion}:
Large models (\textgreater100 places) are intractable - \textbf{No
continuous kinetics}: Cannot model enzyme saturation (Michaelis-Menten)

\hypertarget{hybrid-petri-nets}{%
\subsection{2.2.4 Hybrid Petri Nets}\label{hybrid-petri-nets}}

\textbf{David \& Alla (1992)} introduced \textbf{continuous and hybrid
Petri nets}: - \textbf{Continuous places}: Hold real-valued token counts
(not integers) - \textbf{Continuous transitions}: Fire continuously with
rate dM/dt = v(M) - \textbf{Hybrid nets}: Mix discrete and continuous
places/transitions

\textbf{Semantics}: - Continuous transitions:
\(\frac{dM(p)}{dt} = \sum_{t} v_t \cdot W(t,p) - \sum_{t} v_t \cdot W(p,t)\)
- Rate function v\_t depends on marking (e.g., mass action: v =
k·M(substrate))

\textbf{Advantages for biology}: - \textbf{Enzyme kinetics}: Continuous
transitions model Michaelis-Menten rates - \textbf{Multi-scale}:
Proteins (discrete) + metabolites (continuous) in one model

\textbf{Limitations}: - \textbf{No weak independence theory}: Parallel
execution with shared places undefined - \textbf{Limited arc types}: No
explicit test/inhibitor arc semantics - \textbf{No biochemical
formulas}: Tokens are still abstract (no elemental composition)

\hypertarget{biological-petri-nets-bio-pn}{%
\section{2.3 Biological Petri Nets
(Bio-PN)}\label{biological-petri-nets-bio-pn}}

\hypertarget{early-work-1990s}{%
\subsection{2.3.1 Early Work (1990s)}\label{early-work-1990s}}

\textbf{Reddy et al.~(1993)}: ``Petri Net Representations in Metabolic
Pathways'' - First formal application of Petri nets to biochemistry -
Modeled glycolysis (10 reactions) as classical Petri net -
\textbf{Contribution}: Showed Petri nets can represent metabolic
stoichiometry - \textbf{Limitation}: No kinetics (only qualitative), no
regulation

\textbf{Hofestädt (1994)}: ``A Petri Net Application to Model Metabolic
Processes'' - Extended Reddy's work with enzyme catalysis - Used
\textbf{colored tokens} to distinguish substrates/products -
\textbf{Limitation}: Still no quantitative kinetics

\hypertarget{qualitative-bio-pns-2000s}{%
\subsection{2.3.2 Qualitative Bio-PNs
(2000s)}\label{qualitative-bio-pns-2000s}}

\textbf{Heiner et al.~(2008)}: ``Petri Nets for Systems and Synthetic
Biology'' - Developed \textbf{qualitative Bio-PNs} for signaling
networks - Encoded regulatory logic (activation, inhibition) as arc
types - \textbf{Tool}: Snoopy software (still actively maintained) -
\textbf{Contribution}: Standardized notation for biological arcs -
\textbf{Limitation}: Qualitative only (no kinetic parameters)

\textbf{Koch et al.~(2011)}: ``Modeling Threshold Effects in Biological
Systems'' - Introduced \textbf{read arcs} (test arcs) and
\textbf{inhibitor arcs} - Threshold values for inhibition (e.g., M(p)
\textless{} 5 blocks transition) - \textbf{Limitation}: Thresholds are
constants (not Hill equations), no heterogeneous transitions

\hypertarget{quantitative-bio-pns}{%
\subsection{2.3.3 Quantitative Bio-PNs}\label{quantitative-bio-pns}}

\textbf{Matsuno et al.~(2003)}: ``Hybrid Petri Net Representation of
Gene Regulatory Networks'' - Hybrid Petri nets for gene regulation -
Continuous places (protein concentrations) + discrete places (gene
states) - \textbf{Tool}: Cell Illustrator (commercial) -
\textbf{Contribution}: First hybrid Bio-PN with kinetics -
\textbf{Limitation}: Proprietary formalism, no weak independence theory

\textbf{Gilbert \& Heiner (2006)}: ``From Petri Nets to Differential
Equations'' - Automatic translation of continuous Petri nets to ODE
systems - Mass action kinetics assumed - \textbf{Contribution}:
Formalized PN\textrightarrowODE mapping - \textbf{Limitation}: Only mass action (no
Michaelis-Menten, Hill), no stochastic bursts

\hypertarget{recent-developments-2010s-2020s}{%
\subsection{2.3.4 Recent Developments
(2010s-2020s)}\label{recent-developments-2010s-2020s}}

\textbf{Blätke et al.~(2015)}: ``BioModel Engineering with Petri Nets''
- Comprehensive survey of Bio-PN tools and applications - Case studies:
Signaling (MAPK), metabolism (TCA), gene circuits -
\textbf{Contribution}: Unified terminology, best practices - \textbf{Gap
identified}: ``No tool integrates metabolic kinetics with gene
regulation''

\textbf{Liu \& Heiner (2013)}: ``Multiscale Modeling with Hybrid Petri
Nets'' - Proposed framework for enzyme-catalyzed reactions + gene
expression - \textbf{Limitation}: Still requires two separate models
(metabolism PN + regulation PN)

\textbf{Marwan et al.~(2011)}: ``Petri Nets in Snoopy: A Unifying
Framework'' - Extended Snoopy with stochastic and hybrid PNs -
\textbf{Contribution}: Tool supporting multiple PN classes -
\textbf{Limitation}: No biochemical formula tracking, no weak
independence analysis

\hypertarget{gap-analysis}{%
\subsection{2.3.5 Gap Analysis}\label{gap-analysis}}

\textbf{What existing Bio-PNs provide}: - \checkmark Stoichiometric modeling
(metabolic pathways) - \checkmark Qualitative regulation (activation/inhibition
arcs) - \checkmark Hybrid dynamics (continuous + discrete) - \checkmark Stochastic
simulation (Gillespie algorithm)

\textbf{What is missing} (addressed by this thesis): - \texttimes \textbf{Weak
independence theory}: Parallel execution with shared catalysts/outputs -
\texttimes \textbf{Heterogeneous coexistence}: Continuous + stochastic + timed +
burst in single model - \texttimes \textbf{Arc-level regulatory semantics}: Hill
equations on inhibitor arcs (not just constants) - \texttimes
\textbf{Biochemical formula tracking}: Elemental composition, atomic
conservation - \texttimes \textbf{Integrated metabolic-genetic models}: Single
formalism spanning both layers

\hypertarget{multi-scale-biological-modeling}{%
\section{2.4 Multi-Scale Biological
Modeling}\label{multi-scale-biological-modeling}}

\hypertarget{genome-scale-metabolic-models-gsmm}{%
\subsection{2.4.1 Genome-Scale Metabolic Models
(GSMM)}\label{genome-scale-metabolic-models-gsmm}}

\textbf{Flux Balance Analysis (FBA)} (Varma \& Palsson, 1994): - Models
metabolism as \textbf{stoichiometric matrix} S (metabolites × reactions)
- \textbf{Steady-state assumption}: S · v = 0 (no accumulation) -
\textbf{Optimization}: Maximize biomass flux subject to constraints -
\textbf{Databases}: BiGG Models (7000+ curated GSMMs for bacteria,
yeast, human)

\textbf{Advantages}: - \textbf{Scalability}: Models 1000+ reactions
(entire metabolism) - \textbf{Predictive power}: Predicts growth rates,
gene essentiality

\textbf{Limitations}: - \textbf{No regulation}: Enzyme expression levels
ignored (assumes all enzymes present) - \textbf{No kinetics}: Flux
directions but not rates (no time dynamics) - \textbf{Steady-state
only}: Cannot model transient responses

\hypertarget{gene-regulatory-networks-grn}{%
\subsection{2.4.2 Gene Regulatory Networks
(GRN)}\label{gene-regulatory-networks-grn}}

\textbf{Boolean networks} (Kauffman, 1969): - Genes are binary (on/off)
- Update rules: Gene\_i(t+1) = f(Gene\_j(t), Gene\_k(t), \ldots) -
\textbf{Applications}: Cell differentiation, synthetic circuits

\textbf{Limitations}: - \textbf{No concentrations}: Cannot represent
``high vs.~low ATP'' - \textbf{Discrete time}: Cannot model continuous
dynamics - \textbf{No metabolism}: Genes regulate each other, but
metabolites absent

\textbf{Differential equation models}: - Genes/proteins as continuous
variables - Example: \(\frac{d[X]}{dt} = k_{synth} - k_{deg} \cdot [X]\)
- \textbf{Advantages}: Quantitative, captures kinetics

\textbf{Limitations}: - \textbf{Not compositional}: Adding genes
requires rewriting equations - \textbf{No visual topology}: Regulatory
structure hidden in code - \textbf{Separate from metabolism}:
Metabolites not integrated

\hypertarget{integrated-approaches}{%
\subsection{2.4.3 Integrated Approaches}\label{integrated-approaches}}

\textbf{E-Cell} (Tomita et al., 1999): - Software platform simulating
whole-cell models - Combines multiple formalisms (ODEs, Gillespie,
rule-based) - \textbf{Contribution}: Demonstrated feasibility of
multi-scale simulation - \textbf{Limitation}: Not a formal modeling
language (software tool, not formalism)

\textbf{Virtual Cell} (Schaff et al., 1997): - Spatial models with
reaction-diffusion PDEs - Compartments (cytoplasm, nucleus, membrane) -
\textbf{Contribution}: Spatial resolution - \textbf{Limitation}:
Computationally expensive, no formal analysis (P-invariants)

\textbf{Rule-based modeling} (BioNetGen, Kappa): - Molecular
interactions as rewrite rules - Compactly represents protein complexes
with many states - \textbf{Contribution}: Handles combinatorial
complexity (phosphorylation sites) - \textbf{Limitation}: Not Petri nets
(different formalism), no elemental balance

\hypertarget{why-current-approaches-fall-short}{%
\subsection{2.4.4 Why Current Approaches Fall
Short}\label{why-current-approaches-fall-short}}

\textbf{Fundamental issue}: Existing multi-scale approaches either: 1.
\textbf{Separate models}: Build metabolism model + regulation model,
integrate ad-hoc (no formal semantics) 2. \textbf{Software-specific}:
Tools provide integration (E-Cell, Virtual Cell) but no underlying
formalism 3. \textbf{Limited scope}: Focus on one layer (GSMM for
metabolism, GRN for regulation)

\textbf{This thesis provides}: A \textbf{formal Petri net extension}
enabling integrated modeling with well-defined semantics, analyzability,
and visual topology.

\hypertarget{systems-biology-standards-and-databases}{%
\section{2.5 Systems Biology Standards and
Databases}\label{systems-biology-standards-and-databases}}

\hypertarget{sbml-systems-biology-markup-language}{%
\subsection{2.5.1 SBML (Systems Biology Markup
Language)}\label{sbml-systems-biology-markup-language}}

\textbf{Hucka et al.~(2003)}: XML format for biochemical models -
\textbf{Core}: Species, reactions, compartments, parameters -
\textbf{Extensions}: SBML-qual (qualitative GRNs), SBML-comp (model
composition) - \textbf{Support}: 300+ tools read/write SBML

\textbf{Advantages}: - \textbf{Interoperability}: Exchange models
between tools - \textbf{Standardization}: Widely adopted
(\textgreater10,000 models)

\textbf{Limitations}: - \textbf{Not a formalism}: SBML is a data format,
not a modeling language - \textbf{Separate qualitative/quantitative}:
SBML (kinetics) vs.~SBML-qual (Boolean logic) are disconnected -
\textbf{No formal semantics}: Tool-dependent interpretation

\hypertarget{kegg-kyoto-encyclopedia-of-genes-and-genomes}{%
\subsection{2.5.2 KEGG (Kyoto Encyclopedia of Genes and
Genomes)}\label{kegg-kyoto-encyclopedia-of-genes-and-genomes}}

\textbf{Kanehisa et al.~(2000)}: Database of biological pathways -
\textbf{KEGG COMPOUND}: 18,000+ metabolites (formulas, structures) -
\textbf{KEGG REACTION}: 11,000+ reactions (stoichiometry, EC numbers) -
\textbf{KEGG PATHWAY}: 500+ reference pathways (glycolysis, TCA, etc.) -
\textbf{REST API}: Programmatic access (Chapter 9 uses this)

\textbf{Usage in modeling}: - Import pathways (reaction stoichiometry) -
Fetch compound formulas (C₆H₁₂O₆ for glucose) - Link to enzymes (EC
numbers)

\textbf{Limitations}: - \textbf{Incomplete stoichiometry}: Often omits
cofactors (H₂O, H⁺) - \textbf{No kinetics}: Reaction topology only, no
rate constants

\hypertarget{brenda-enzyme-database}{%
\subsection{2.5.3 BRENDA (Enzyme
Database)}\label{brenda-enzyme-database}}

\textbf{Schomburg et al.~(2004)}: Comprehensive enzyme kinetics -
\textbf{2.7 million} parameter entries (Km, kcat, Ki, pH optima) -
\textbf{83,000+ enzymes} classified by EC number -
\textbf{Organism-specific}: Data from bacteria, yeast, human, etc. -
\textbf{SOAP API}: Programmatic access (Chapter 10 uses this)

\textbf{Applications}: - Parameter inference for models (Km for glucose
≈ 0.1 mM) - Organism-specific parameterization (yeast vs.~human
kinetics)

\textbf{Challenges}: - \textbf{High variance}: Same enzyme, different
labs \textrightarrow 10× differences - \textbf{Incomplete coverage}: Not all enzymes
have kinetic data

\hypertarget{other-databases}{%
\subsection{2.5.4 Other Databases}\label{other-databases}}

\textbf{ChEBI} (Chemical Entities of Biological Interest): - Molecular
structures, formulas, synonyms - More detailed than KEGG (includes
protonation states)

\textbf{SABIO-RK} (Reaction Kinetics Database): - Curated kinetic laws
(full rate equations, not just Km) - Smaller than BRENDA (50,000
entries) but higher quality

\textbf{BiGG Models}: - Genome-scale metabolic reconstructions - Flux
constraints, gene-protein-reaction associations

\textbf{Integration in this thesis}: - \textbf{KEGG}: Formula retrieval
(Chapter 9) - \textbf{BRENDA}: Parameter inference (Chapter 10) -
\textbf{ChEBI}: Fallback for formulas (future work)

\hypertarget{related-tools}{%
\section{2.6 Related Tools}\label{related-tools}}

\hypertarget{snoopy-brandenburg-university-of-technology}{%
\subsection{2.6.1 Snoopy (Brandenburg University of
Technology)}\label{snoopy-brandenburg-university-of-technology}}

\textbf{Heiner et al.~(2012)}: ``Snoopy - A Unifying Petri Net Tool'' -
\textbf{Supports}: Classical, timed, stochastic, hybrid Petri nets -
\textbf{Features}: - Graphical editor (drag-and-drop) - Simulation (ODE,
Gillespie, hybrid) - Model checking (CTL properties) - SBML
import/export - \textbf{Biological focus}: Signaling networks, metabolic
pathways

\textbf{Strengths}: - Open-source, actively maintained - Excellent
visualization - Structural analysis (P-invariants, reachability graph)

\textbf{Limitations}: - \textbf{No weak independence analysis}:
Parallelism not exploited - \textbf{No biochemical formulas}: Tokens are
abstract - \textbf{Limited regulation}: Inhibitor arcs have constant
thresholds (no Hill equations) - \textbf{Separate models for
metabolism/regulation}: No unified formalism

\hypertarget{cell-illustrator-university-of-tokyo}{%
\subsection{2.6.2 Cell Illustrator (University of
Tokyo)}\label{cell-illustrator-university-of-tokyo}}

\textbf{Nagasaki et al.~(2010)}: Hybrid Petri net tool - \textbf{Hybrid
dynamics}: Continuous + discrete + stochastic - \textbf{Biological
templates}: Gene expression, signaling cascades - \textbf{3D
visualization}: Network layout algorithms

\textbf{Strengths}: - Powerful hybrid simulation - Large library of
biological models

\textbf{Limitations}: - \textbf{Proprietary}: Commercial license
required (not open-source) - \textbf{Custom formalism}: Not standard
Petri nets (tool-specific notation) - \textbf{No KEGG/BRENDA
integration}: Manual parameter entry

\hypertarget{copasi-complex-pathway-simulator}{%
\subsection{2.6.3 COPASI (Complex Pathway
Simulator)}\label{copasi-complex-pathway-simulator}}

\textbf{Hoops et al.~(2006)}: Biochemical system simulator - \textbf{ODE
simulation}: Deterministic, stochastic (Gillespie), hybrid -
\textbf{Parameter estimation}: Fit models to experimental data -
\textbf{Optimization}: Metabolic flux optimization - \textbf{SBML
support}: Import/export

\textbf{Strengths}: - Widely used (5000+ citations) - Parameter fitting
(least-squares, genetic algorithms) - Sensitivity analysis

\textbf{Limitations}: - \textbf{Not Petri nets}: Reaction network
formalism (different from PNs) - \textbf{No regulation arcs}: Inhibition
encoded in rate laws (not topology) - \textbf{Single-scale}:
Metabolism-focused (gene regulation requires separate SBML-qual model)

\hypertarget{celldesigner-systems-biology-institute}{%
\subsection{2.6.4 CellDesigner (Systems Biology
Institute)}\label{celldesigner-systems-biology-institute}}

\textbf{Funahashi et al.~(2003)}: Visual SBML editor - \textbf{Graphical
notation}: Process diagrams (SBGN standard) - \textbf{SBML generation}:
Automatically creates SBML from diagrams - \textbf{Simulation}:
Integrates with COPASI, CellML

\textbf{Strengths}: - User-friendly visual editor - SBML standardization

\textbf{Limitations}: - \textbf{Not Petri nets}: Process diagrams
(different semantics) - \textbf{No formal analysis}: Cannot compute
P-invariants, reachability - \textbf{Separate regulation}: Metabolic and
regulatory diagrams disconnected

\hypertarget{charlie-model-checker}{%
\subsection{2.6.5 Charlie (Model Checker)}\label{charlie-model-checker}}

\textbf{Heiner et al.~(2015)}: Verification tool for Petri nets -
\textbf{Model checking}: CTL, LTL temporal logic properties -
\textbf{Symbolic methods}: BDDs for state space exploration -
\textbf{Biological properties}: Verifies liveness, boundedness,
reachability

\textbf{Strengths}: - Formal verification (prove properties hold) -
Handles large state spaces (symbolic encoding)

\textbf{Limitations}: - \textbf{Verification only}: Not a modeling tool
(requires Snoopy for model creation) - \textbf{No kinetics}: Qualitative
properties only (not quantitative simulation)

\hypertarget{comparison-summary-1}{%

\hypertarget{concurrency-theory}{%
\subsection{2.7.1 Concurrency Theory}\label{concurrency-theory}}

\textbf{Independence of transitions} (classical definition): -
Transitions t₁, t₂ are \textbf{independent} if: -
\((\bullet t_1 \cup t_1\bullet) \cap (\bullet t_2 \cup t_2\bullet) = \emptyset\)
- (No shared places in neighborhoods) - \textbf{Consequence}: Can fire
\textbf{concurrently} without conflict

\textbf{Diamond property} (Mazurkiewicz, 1987): - If t₁, t₂ are
independent and both enabled at M: - M \textrightarrow\^{}\{t₁\} M₁ \textrightarrow\^{}\{t₂\} M₁₂ -
M \textrightarrow\^{}\{t₂\} M₂ \textrightarrow\^{}\{t₁\} M₁₂ - (Same final state M₁₂ regardless of
order)

\textbf{Limitation for biology}: - Enzymes catalyze multiple reactions
(shared place) \textrightarrow Not independent by classical definition - But
\textbf{biologically}, these reactions don't conflict (enzyme is
preserved)

\textbf{This thesis contribution}: Weak independence relaxes the
condition to allow shared test arcs and outputs while preserving diamond
property.

\hypertarget{process-calculi}{%
\subsection{2.7.2 Process Calculi}\label{process-calculi}}

\textbf{CCS} (Calculus of Communicating Systems, Milner 1980): -
Algebraic formalism for concurrent processes - Composition operator (P
\textbar{} Q) runs P, Q in parallel

\textbf{π-calculus} (Milner et al., 1992): - Extends CCS with mobile
processes (channels can be passed)

\textbf{Stochastic π-calculus} (Priami, 1995): - Adds stochastic rates
to reactions - Used in computational biology (BioAmbients, Beta-binders)

\textbf{Relation to Petri nets}: - Process calculi and Petri nets are
\textbf{equivalent in expressiveness} (both Turing-complete) - Petri
nets are \textbf{graphical} (visual topology), process calculi are
\textbf{textual} (algebraic) - Choice: Petri nets preferred in systems
biology for \textbf{visual reasoning}

\hypertarget{chemical-reaction-network-theory}{%
\subsection{2.7.3 Chemical Reaction Network
Theory}\label{chemical-reaction-network-theory}}

\textbf{Feinberg (1987)}: Deficiency theory - Analyzes steady states of
reaction networks - \textbf{Deficiency zero theorem}: Networks with
deficiency δ=0 have unique positive steady state

\textbf{Relationship to Petri nets}: - Reaction networks are
\textbf{continuous Petri nets} with mass action kinetics -
Stoichiometric matrix S corresponds to PN incidence matrix

\textbf{Limitation}: - Mass action only (no Michaelis-Menten, Hill) - No
gene regulation (reactions among metabolites only)

\hypertarget{stochastic-simulation}{%
\subsection{2.7.4 Stochastic Simulation}\label{stochastic-simulation}}

\textbf{Gillespie (1977)}: Stochastic Simulation Algorithm (SSA) -
\textbf{Exact algorithm} for simulating chemical master equation (CME) -
Two random numbers per step: 1. When does next reaction occur? (τ
\textasciitilde{} Exponential) 2. Which reaction fires? (Weighted choice
by propensity)

\textbf{τ-leaping} (Gillespie, 2001): - Approximate method: Fire
multiple reactions per step - Faster but loses exactness

\textbf{Hybrid methods} (Haseltine \& Rawlings, 2002): - Fast reactions:
Continuous (ODE) - Slow reactions: Stochastic (Gillespie) -
\textbf{Challenge}: Partitioning (which reactions are fast?)

\textbf{This thesis contribution}: Hybrid scheduler coordinates ODE +
Gillespie + Timed + Burst engines without manual partitioning (user
specifies transition type explicitly).

\hypertarget{gap-summary}{%
\section{2.8 Gap Summary}\label{gap-summary}}

\textbf{Existing work provides}: - \checkmark Petri net theory (classical,
timed, stochastic, hybrid) - \checkmark Biological applications (metabolic
pathways, signaling networks) - \checkmark Tools (Snoopy, COPASI, CellDesigner)
- \checkmark Databases (KEGG, BRENDA, SBML) - \checkmark Simulation algorithms (ODE,
Gillespie, hybrid)

\textbf{What is missing} (this thesis addresses): 1. \textbf{Weak
independence theory}: Formal framework for parallel execution with
shared catalysts/outputs 2. \textbf{Heterogeneous transition
coexistence}: Continuous + stochastic + timed + burst in single model
with unified semantics 3. \textbf{Arc-level regulatory semantics}: Hill
equations, threshold formulas on arcs (not external code) 4.
\textbf{Biochemical formula tracking}: Elemental composition, atomic
conservation verification 5. \textbf{Integrated metabolic-genetic
formalism}: Single framework spanning biochemistry and gene regulation
6. \textbf{Tool integration}: Automated KEGG (formulas) + BRENDA
(parameters) enrichment

\textbf{Positioning}: This thesis is the \textbf{first} to provide all
six capabilities in a unified Petri net formalism.
