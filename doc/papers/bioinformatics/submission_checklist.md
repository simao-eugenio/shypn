# Bioinformatics Submission Checklist

## Pre-Submission Requirements

### Manuscript Files
- [ ] Main manuscript (PDF compiled from LaTeX)
- [ ] LaTeX source files (.tex, .bib)
- [ ] Figures (high resolution: 1200 dpi for line drawings, 350 dpi for photos)
- [ ] Cover letter (cover_letter.txt)

### Author Information
- [ ] ORCID iD (REQUIRED - register at https://orcid.org/ if needed)
- [ ] Complete affiliation and contact email
- [ ] Confirm sole authorship

### Manuscript Content
- [ ] Title includes software name if applicable
- [ ] Structured abstract with required sections:
  - [ ] Motivation
  - [ ] Results
  - [ ] Availability and Implementation (with GitHub URL)
  - [ ] Contact (email)
- [ ] Word count: ~5000 words (7 pages) ✓
- [ ] All references formatted correctly
- [ ] All figures cited in text
- [ ] Data availability statement included

### Software/Code Requirements
- [ ] Source code publicly available: https://github.com/simao-eugenio/shypn ✓
- [ ] Open source license stated (MIT) ✓
- [ ] Software will be maintained for 2+ years ✓
- [ ] Installation instructions provided
- [ ] Test data/examples available
- [ ] Documentation complete

### Ethical/Policy Requirements
- [ ] No plagiarism (will be screened with iThenticate)
- [ ] No AI-generated content used (or properly disclosed if used)
- [ ] No conflicts of interest to declare ✓
- [ ] Funding sources declared (or "No funding" stated) ✓
- [ ] All authors approve submission (N/A - sole author)

### Data Requirements
- [ ] All data from public repositories (BioModels) ✓
- [ ] Model identifiers provided in manuscript ✓
- [ ] Analysis reproducible from provided data

### Cover Letter
- [ ] Explains suitability for Bioinformatics ✓
- [ ] States manuscript category (Original Paper - Systems Biology) ✓
- [ ] Confirms originality and not under consideration elsewhere ✓
- [ ] Describes novel contributions ✓
- [ ] Software availability clearly stated ✓

## Submission Process

### Online Submission Portal
- URL: https://mc.manuscriptcentral.com/bioinformatics
- [ ] Create account (if first time)
- [ ] Select "Original Paper" as manuscript type
- [ ] Select "Systems Biology" as category
- [ ] Upload PDF (manuscript)
- [ ] Upload LaTeX source files (after PDF accepted)
- [ ] Upload cover letter
- [ ] Enter ORCID iD (REQUIRED)

### During Submission
- [ ] Provide suggested reviewers (optional but recommended)
  - Suggest 3-5 experts in Petri nets, systems biology, or computational biology
  - Ensure no conflicts of interest
  - Provide names, institutions, and email addresses
- [ ] List any reviewers to exclude (if applicable)
- [ ] Confirm all policies accepted

## Post-Submission

### What to Expect
- Editorial pre-screening: 1-2 weeks
- Peer review: 4-8 weeks (if not desk-rejected)
- Typically sent to 3 reviewers
- Decision types: Accept, Minor Revision, Major Revision, Reject

### If Accepted
- [ ] Sign publishing agreement via SciPris portal
- [ ] Pay open access charge ($4,188, or check for institutional agreement)
  - ISCB members receive 15% discount
  - Check waiver eligibility: https://academic.oup.com/pages/open-research/open-access/charges-licences-and-self-archiving/apc-waiver-policy
- [ ] Review proofs carefully
- [ ] Update any preprints with DOI after publication

## Important Notes

1. **Page Limits**: 7 pages for Original Papers. Manuscripts exceeding by 20%+ may be rejected without review.

2. **Machine Learning Papers**: Not applicable to your paper, but if it were, would need dedicated subsection on training/test data.

3. **Format-Free Submission**: You can submit without journal formatting initially, but will need to format for revision/acceptance.

4. **Acceptance Rate**: ~30% of submissions are accepted. Pre-screening may return papers without review if not suitable.

5. **Open Access**: Bioinformatics is fully open access. All papers require open access charges.

6. **Fast Publication**: Accepted manuscripts published online within 1 week as "Advance Articles."

## Final Checks Before Clicking Submit

- [ ] Cover letter addresses significance and suitability
- [ ] ORCID iD ready to enter
- [ ] All files uploaded and verified
- [ ] Abstract has all required sections
- [ ] Software is publicly accessible at stated URL
- [ ] References compiled correctly (no question marks)
- [ ] Figures are publication quality
- [ ] Contact email is institutional (not personal)
- [ ] You can pay open access charges (or have waiver plan)
