**Duration**: 2-3 hours (manual GUI work)

**Models to Create** (7 total):

#### 1. `strong_independence.shy` ⭐ Priority: HIGH
**Purpose**: Baseline for independence theory (Chapter 5, Fig 5.1)

**Specification**:
- **Places**: P1, P2, P3, P4
- **Transitions**: t1, t2
- **Arcs**: 
  - P1 → t1 (weight=1)
  - t1 → P2 (weight=1)
  - P3 → t2 (weight=1)
  - t2 → P4 (weight=1)
- **Initial marking**: P1=1, P3=1, others=0
- **Layout**: Horizontal, two parallel chains
  ```
  P1 → [t1] → P2        P3 → [t2] → P4
  ```

#### 2. `convergent_synthesis.shy` ⭐ Priority: HIGH
**Purpose**: Demonstrate Mode 2 violation (Chapter 5, Fig 5.2)

**Specification**:
- **Places**: Glucose, Lactate, Pyruvate
- **Transitions**: t1 (glycolysis step), t2 (lactate oxidation)
- **Arcs**:
  - Glucose → t1 (weight=1)
  - t1 → Pyruvate (weight=1)
  - Lactate → t2 (weight=1)
  - t2 → Pyruvate (weight=1)
- **Initial marking**: Glucose=5, Lactate=3, Pyruvate=0
- **Layout**: Convergent Y-shape pointing right
  ```
  Glucose → [t1] ↘
                   Pyruvate
  Lactate → [t2] ↗
  ```

#### 3. `shared_catalyst.shy` ⭐ Priority: HIGH
**Purpose**: Enzyme reuse pattern (Chapter 5, Fig 5.3)

**Specification**:
- **Places**: S1, S2, PGI (enzyme), P1, P2
- **Transitions**: t1, t2
- **Arcs**:
  - S1 → t1 → P1 (normal arcs)
  - S2 → t2 → P2 (normal arcs)
  - PGI ⇢ t1 (test arc, dashed)
  - PGI ⇢ t2 (test arc, dashed)
- **Initial marking**: S1=2, S2=2, PGI=1, P1=0, P2=0
- **Layout**: Two parallel reactions, enzyme in center
  ```
  S1 → [t1] → P1
       ↗  ↖
      PGI
       ↖  ↗
  S2 → [t2] → P2
  ```

#### 4. `feedback_regulation.shy` ⭐ Priority: MEDIUM
**Purpose**: Complex regulation (Chapter 5, Fig 5.4)

**Specification**:
- **Places**: Glucose, ATP, G6P, F-1,6-BP
- **Transitions**: HK (hexokinase), PFK (phosphofructokinase)
- **Arcs**:
  - Glucose → HK (normal)
  - ATP → HK (normal)
  - HK → G6P (normal)
  - G6P → PFK (normal)
  - PFK → F-1,6-BP (normal)
  - ATP ⇢ PFK (inhibitor arc, dotted red)
- **Initial marking**: Glucose=10, ATP=5, G6P=0, F-1,6-BP=0
- **Layout**: Linear pathway with feedback loop from ATP
  ```
  Glucose → [HK] → G6P → [PFK] → F-1,6-BP
             ↑            ⤫
             ATP ─────────┘ (inhibitor)
  ```

#### 5. `conflict_mode.shy` ⭐ Priority: HIGH
**Purpose**: Define Mode 1 (Chapter 5, Fig 5.5)

**Specification**:
- **Places**: ATP, P1, P2
- **Transitions**: t1, t2
- **Arcs**:
  - ATP → t1 (weight=1)
  - t1 → P1 (weight=1)
  - ATP → t2 (weight=1)
  - t2 → P2 (weight=1)
- **Initial marking**: ATP=3, P1=0, P2=0 (3 tokens to show conflict)
- **Layout**: Divergent from ATP
  ```
       ┌→ [t1] → P1
  ATP ─┤
       └→ [t2] → P2
  ```

#### 6. `convergent_mode.shy` ⭐ Priority: HIGH
**Purpose**: Define Mode 2 (Chapter 5, Fig 5.6)

**Specification**:
- **Places**: S1, S2, P
- **Transitions**: t1, t2
- **Arcs**:
  - S1 → t1 → P
  - S2 → t2 → P
- **Initial marking**: S1=2, S2=3, P=0
- **Layout**: Convergent Y-shape
  ```
  S1 → [t1] ↘
              P
  S2 → [t2] ↗
  ```

#### 7. `regulatory_mode.shy` ⭐ Priority: HIGH
**Purpose**: Define Mode 3 (Chapter 5, Fig 5.7)

**Specification**:
- **Places**: S1, S2, Enzyme, P1, P2
- **Transitions**: t1, t2
- **Arcs**:
  - S1 → t1 → P1 (normal)
  - S2 → t2 → P2 (normal)
  - Enzyme ⇢ t1 (test, dashed)
  - Enzyme ⇢ t2 (test, dashed)
- **Initial marking**: S1=2, S2=2, Enzyme=1, P1=0, P2=0
- **Layout**: Two parallel reactions with central catalyst
  ```
  S1 → [t1] → P1
       ↗  ↖
    Enzyme
       ↖  ↗
  S2 → [t2] → P2
  ```

**Instructions for User**:

   ```bash

   # Select model to edit
   ```

2. **Review & Refine Layout**:
   - Drag places/transitions for optimal spacing
   - Aim for left-to-right flow where possible
   - Ensure labels are readable (not overlapping arcs)
   - Add margins around edges (20px minimum)

3. **Verify Labels**:
   - Place names match LaTeX captions
   - Transition names clear and concise
   - Remove any debug labels

4. **Fine-tune Visual Style**:
   - Check place radius (30px default, adjust if needed)
   - Verify transition size (15x40px default)
   - Confirm arc styles (test=dashed, inhibitor=dotted red)
   - Ensure colors are print-friendly (avoid bright neons)

5. **Set Initial Markings**:
   - For conflict examples: 3 tokens on shared input
   - For convergent examples: 0 tokens on output (show accumulation)
   - For catalyst examples: 1 token on enzyme place
   - For independence: 1 token on each input place

6. **Save Model**:
   - File → Save (Ctrl+S)
   - Verify `.shy` file updated

7. **Repeat** for all 10 models (7 conceptual + 3 biological)
