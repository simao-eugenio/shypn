# Cross-Reference Database

Cross-reference database for mapping between biochemical database identifiers (KEGG, ChEBI, BiGG).

## Overview

The cross-reference database enables conversion between different compound identifier systems:

- **KEGG Compound IDs** (C00002) - Primary system used by Shypn
- **ChEBI IDs** (CHEBI:15422) - Chemical Entities of Biological Interest
- **BiGG IDs** (atp_c) - Biochemical, Genetic and Genomic database

## Architecture

### Base Class (base.py)

Abstract base class `CrossReferenceMapperBase` defines the interface:
- `chebi_to_kegg()` - Convert ChEBI ID to KEGG
- `kegg_to_chebi()` - Convert KEGG ID to ChEBI(s)
- `bigg_to_kegg()` - Convert BiGG ID to KEGG
- `resolve_alias()` - Resolve common name to KEGG ID
- `get_statistics()` - Get mapping counts

### Implementation (xref_database.py)

`CrossReferenceDatabase` provides concrete implementation:
- Loads static JSON mapping files
- LRU caching for fast repeated lookups
- Graceful degradation when files unavailable
- Bidirectional mapping support

### Data Files (data/)

Static JSON files containing mappings:
- `kegg_to_chebi.json` - KEGG → ChEBI mappings (~20,000)
- `chebi_to_kegg.json` - ChEBI → KEGG mappings (~18,000)
- `bigg_to_kegg.json` - BiGG → KEGG mappings (~3,000)
- `compound_aliases.json` - Common names → KEGG

## Generating Mapping Files

The mapping files are generated by `scripts/xref_builder.py` from online sources:

```bash
# Run builder script (requires internet connection)
python scripts/xref_builder.py
```

**Data Sources:**
1. **KEGG REST API** - https://rest.kegg.jp/conv/chebi/compound
2. **BiGG Models API** - http://bigg.ucsd.edu/api/v2/

**Notes:**
- BiGG API queries may take several minutes due to rate limiting
- Requires `requests` package: `pip install requests`
- Generated files stored in `src/shypn/thermodynamics/database/xref/data/`

## Usage

### Basic Usage

```python
from shypn.thermodynamics.database.xref import CrossReferenceDatabase

# Initialize database
xref = CrossReferenceDatabase()

# ChEBI → KEGG conversion
kegg_id = xref.chebi_to_kegg("CHEBI:15422")
print(kegg_id)  # C00002 (ATP)

# KEGG → ChEBI conversion (may return multiple)
chebi_ids = xref.kegg_to_chebi("C00002")
print(chebi_ids)  # ['CHEBI:15422', 'CHEBI:30616']

# BiGG → KEGG conversion
kegg_id = xref.bigg_to_kegg("atp_c")
print(kegg_id)  # C00002

# Alias resolution
kegg_id = xref.resolve_alias("ATP")
print(kegg_id)  # C00002
```

### Integration with SBML Mapper

The `SBMLCompoundMapper` uses the cross-reference database automatically:

```python
from shypn.thermodynamics.sbml_compound_mapper import SBMLCompoundMapper

# Initialize mapper with cross-reference enabled (default)
mapper = SBMLCompoundMapper(use_xref=True)

# Map SBML species (tries KEGG → ChEBI → BiGG → name matching)
kegg_id = mapper.map_species(species)
```

**Annotation Priority:**
1. KEGG compound annotation (direct)
2. ChEBI annotation → KEGG (via xref)
3. BiGG annotation → KEGG (via xref)
4. Name matching (fallback)

## Features

### LRU Caching

Repeated lookups are cached for performance:
```python
# First lookup (cache miss)
kegg_id = xref.chebi_to_kegg("CHEBI:15422")

# Second lookup (cache hit, faster)
kegg_id = xref.chebi_to_kegg("CHEBI:15422")
```

Cache size: 1024 entries per method

### ID Normalization

ChEBI IDs automatically normalized:
```python
# Both work identically
xref.chebi_to_kegg("CHEBI:15422")
xref.chebi_to_kegg("15422")
```

BiGG compartment suffixes handled:
```python
# Both map to same KEGG ID
xref.bigg_to_kegg("atp_c")  # with compartment
xref.bigg_to_kegg("atp")    # without compartment
```

### Graceful Degradation

Database continues to work even if mapping files unavailable:
```python
xref = CrossReferenceDatabase()

# Check availability
if xref.is_available():
    print("Database loaded successfully")
else:
    print("Database unavailable, using fallback methods")

# Get statistics
stats = xref.get_statistics()
print(f"Loaded {stats['kegg_to_chebi']} KEGG→ChEBI mappings")
```

## Performance

**Lookup Times:**
- First lookup (cache miss): < 0.1 ms
- Cached lookup (cache hit): < 0.01 ms
- Database load time: < 100 ms

**Memory Usage:**
- Mapping files on disk: ~10-20 MB (JSON)
- In-memory loaded: ~30-50 MB
- Cache overhead: ~100 KB (1024 entries)

## Examples

### ATP (Multiple ChEBI IDs)

```python
# ATP has multiple ChEBI representations
chebi_ids = xref.kegg_to_chebi("C00002")
# ['CHEBI:15422', 'CHEBI:30616', ...]

# All map back to same KEGG ID
for chebi_id in chebi_ids:
    assert xref.chebi_to_kegg(chebi_id) == "C00002"
```

### Glucose Variants

```python
# Different glucose forms
xref.chebi_to_kegg("CHEBI:4167")   # D-glucose → C00031
xref.chebi_to_kegg("CHEBI:17634")  # alpha-D-glucose → C00031
xref.chebi_to_kegg("CHEBI:15903")  # beta-D-glucose → C00031
```

### BiGG Compartments

```python
# BiGG uses compartment suffixes
xref.bigg_to_kegg("atp_c")   # cytosolic ATP → C00002
xref.bigg_to_kegg("atp_m")   # mitochondrial ATP → C00002
xref.bigg_to_kegg("atp_e")   # extracellular ATP → C00002
```

## Limitations

1. **One-way BiGG conversion** - BiGG → KEGG only (not KEGG → BiGG)
2. **Compartment loss** - BiGG compartment info discarded during conversion
3. **Ambiguous ChEBI IDs** - Multiple ChEBI IDs may map to one KEGG ID
4. **Static database** - Requires manual updates (run xref_builder.py)
5. **Coverage gaps** - Not all compounds have cross-references
